此目录用于存放使用说明文档（.pdf / .xps）。

主窗口菜单「帮助 → 使用说明」的打开规则：
- Win10 及以上且已安装 WebView2：优先打开此目录下第一个 .pdf（用 WebView2 预览），没有 .pdf 时回退 .xps；
- 其他环境（含 Win7、未安装 WebView2）：优先打开第一个 .xps（用 DocumentViewer 预览），没有 .xps 时回退 .pdf。

维护提示：使用说明书的源文件是仓库根目录的「使用说明书.md」，改完源文件后需要重新导出 PDF 与 XPS 两个文件并替换本目录，否则随包发布的是旧版说明。
构建/发布时，此目录会随程序一起部署。
