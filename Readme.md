# 烧录 (ShaoLu)

一款基于 WPF 的桌面自动化工具，通过图像识别和模拟输入实现 GUI 自动化操作。

## 步骤类型说明

### 1. 点击识图 (ClickImage)

**功能：** 在屏幕上查找目标图片，找到后自动点击。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件（支持 png/jpg/jpeg），可通过"选择"按钮选取或"编辑"按钮裁剪区域 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1，值越高匹配越严格 | 0.85 |
| 点击次数 | 找到图片后的点击次数 | 1 |
| 点击间隔 | 多次点击时，每次点击之间的间隔时间（秒） | 0.1 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒），超时未找到则步骤失败 | 3 |

**使用流程：**
1. 点击"选择"按钮选取目标图片
2. 如需精确匹配区域，点击"编辑"按钮裁剪图片的识别区域
3. 调整相似度阈值（建议 0.8~0.95）
4. 设置点击次数和间隔

---

### 2. 查找识图 (FindImage)

**功能：** 在屏幕上查找目标图片，仅判断是否找到（不点击），可用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1 | 0.85 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒） | 3 |

**使用流程：**
1. 选择目标图片
2. 设置相似度和超时参数
3. 步骤执行结果：找到为 `true`，未找到为 `false`
4. 可配合"如果真"跳转实现条件分支

---

### 3. 多图点击 (ClickImages)

**功能：** 依次在屏幕上查找多张目标图片，全部找到后逐一点击。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 图片列表 | 通过 + / - 按钮添加或移除多张目标图片，每张图片可独立设置相似度 | - |
| 点击次数 | 找到图片后的点击次数 | 1 |
| 点击间隔 | 多次点击之间的间隔（秒） | 0.1 |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 超时时间 | 每张图片的查找超时时间（秒） | 3 |

**使用流程：**
1. 点击 **+** 按钮添加多张目标图片
2. 分别选择每张图片并设置相似度
3. 运行时按列表顺序依次查找并点击

---

### 4. 多图查找 (FindImages)

**功能：** 同时在屏幕上查找多张目标图片，判断是否全部找到（不点击），用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 图片列表 | 通过 + / - 按钮添加或移除多张目标图片 | - |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找的最大超时时间（秒） | 3 |

**使用流程：**
1. 添加多张需要查找的目标图片
2. 设置查找参数
3. 所有图片都找到时结果为 `true`，否则为 `false`

---

### 5. 输入文字 (TypeText)

**功能：** 模拟键盘输入一段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 需要输入的文本内容 | - |
| 按键间隔 | 每个按键之间的延迟时间（秒），设为 0 则使用安全快速输入模式 | 0.05 |

**使用流程：**
1. 在"输入内容"框中填写要输入的文字
2. 调整按键间隔（中文输入建议适当增大间隔）
3. 运行时会在当前焦点位置逐字输入

---

### 6. 多次输入 (TypeTextMore)

**功能：** 按照前缀、 infix、后缀的组合格式，批量循环输入多段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 当前要输入的文本 | - |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 前缀/Infix/后缀 | 组合输入时的文本片段 | - |

---

### 7. 从文件输入 (TypeTextFromFile)

**功能：** 从文件（txt/csv/xlsx）中读取内容列表，每次执行输入一行，逐行递增。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 文件路径 | 支持的格式：`.txt`、`.csv`、`.xlsx` | - |

**使用流程：**
1. 点击"选择"按钮加载数据文件
2. 支持的文件格式：
   - **txt/csv**：按换行符、逗号、分号等分隔
   - **xlsx**：读取第一列的每行数据
3. 每次执行步骤时，自动输入下一行内容
4. 所有内容输入完毕后步骤报错

---

### 8. 弹出框 (Popup)

**功能：** 弹出自定义消息框，等待用户点击按钮，根据点击结果返回 true/false，可用于流程控制和人工干预。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 标题 | 弹窗标题 | - |
| 弹出文字 | 弹窗显示的文本内容 | - |
| 字体/颜色 | 可自定义弹窗文字的字体和颜色 | Arial 14号 黑色 |
| 弹窗类型 | Information / Warning / Error / Question | Information |
| 按钮 | 自定义弹窗按钮，通过 + / - 添加或移除 | OK |

**使用流程：**
1. 设置弹窗标题和内容
2. 选择弹窗类型（影响图标显示）
3. 自定义按钮文本和返回值
4. 运行时弹出对话框，用户点击按钮后根据返回值决定步骤结果（true/false）
5. 可配合条件跳转实现人工确认环节

---

## 通用属性

所有步骤都支持以下通用属性：

| 属性 | 说明 |
|------|------|
| 启用 | 是否启用该步骤（取消勾选则跳过） |
| 名称 | 步骤名称 |
| 描述 | 步骤描述信息 |
| 等待时间 | 执行前的等待延迟（秒） |
| 如果真 | 步骤结果为 true 时跳转到指定行号 |
| 如果假 | 步骤结果为 false 时跳转到指定行号 |
