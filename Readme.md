# 烧录 (ShaoLu)

一款基于 WPF 的桌面自动化工具，通过图像识别、OCR 文字识别和模拟输入实现 GUI 自动化操作。

---

## 快速开始

1. 启动程序后，在主界面工具栏的「步骤」组添加自动化步骤
2. 每个步骤可设置名称、描述、启用/禁用、等待时间、条件跳转等通用属性
3. 在步骤列表中选中某个步骤，右侧「步骤详情」面板即显示它的参数配置
4. 配置完成后点击「运行」开始执行自动化流程
5. 运行/停止默认热键为 Ctrl+Alt+F9 / Ctrl+Alt+F10（全局生效；热键值保存在 `settings.json` 的 Step 段，界面不提供修改入口）
6. 新建、保存、另存为以及「编辑」「步骤」两组工具栏需要先登录（「管理 → 登录」）才可用

## 主界面功能

### 菜单栏

菜单依次为：文件 / 编辑 / 设置 / 管理 / 烧录统计 / 扩展 / 语言 / 帮助 / 退出。

### 文件菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 新建 | Ctrl+N | 清空当前步骤列表（需登录） |
| 打开 | Ctrl+O | 打开步骤文件（支持 .autostep 和旧版 .json），不需要登录 |
| 保存 | Ctrl+S | 保存步骤文件（需登录） |
| 另存为 | Ctrl+Shift+S | 另存为新文件（需登录） |
| 最近打开的文件 | - | 展示最近打开的 10 个文件，点击即可直接打开 |

### 编辑菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 撤销 / 恢复 | Ctrl+Z / Ctrl+Y | 步骤列表整体的撤销与恢复（最多保留 50 步） |
| 撤销本步骤编辑 / 恢复本步骤编辑 | - | 只回滚当前选中步骤内部的参数修改 |
| 上移 / 下移 | - | 移动选中步骤，支持多选批量移动 |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V | 步骤的复制、剪切与粘贴 |
| 删除 | - | 删除选中步骤 |
| 添加步骤 | - | 单独一段（与其他项隔开），列出全部步骤类型，添加位置与工具栏一致：插在当前选中步骤之后 |

### 运行控制

- **运行**：开始执行自动化流程（默认热键 Ctrl+Alt+F9）
- **暂停/继续**：在步骤间暂停执行，可恢复继续
- **停止**：终止当前运行（默认热键 Ctrl+Alt+F10）

### 工具栏分组

工具栏分为运行、编辑、步骤三组，运行组之后还有一组视图切换按钮：

- **运行组**（常显）：运行 / 暂停（继续）/ 停止
- **视图切换**：运行组之后的「表格 / 流程图」两个按钮互斥切换，两种视图共用同一份步骤（详见[流程图视图](#流程图视图)）
- **编辑组**：刷新、撤销、恢复、上移、下移、复制、剪切、粘贴、删除
- **步骤组**：下拉按钮按类型分组——识图与文字（识图、查找识图、文字、文字(多)、文字(从文件)、鼠标操作）、获取文本（获取文本、统计信息、烧录配置、窗口操作、空步骤）、多线程（5 个步骤）、弹出窗口、扫码（扫码、上传 Acbel）、用户输入

「编辑」「步骤」两组可点组名展开/收起（▸/▾ 指示状态）。宽度足够时两组都展开；放不下时自动折叠编辑组，此情形下手动展开其中一组会收起另一组。

### 状态栏与窗口标题

- **窗口标题**：程序名 + 当前脚本名，未保存时显示「未保存」
- **状态栏左侧**：当前正在执行的步骤名（未运行时为空）
- **状态栏右侧**：运行状态（未运行 / 运行中 / 已暂停）
- **默认窗口尺寸**：打开时取主屏 60% 宽 × 60% 高（下限 800 × 500，并留出屏幕边距）
- **多线程区域**：区域内的步骤连同「多线程开始」「多线程区域结束」两行统一用淡蓝色背景（`#FFE8F3FF`），出错时仍为红色；可在开始行上折叠/展开（详见步骤类型第 16 节）

### 其他菜单

- **设置**：App 设置（字体、执行日志保留天数，默认 30 天）与 Step 设置（运行行为、新建步骤默认参数、流程图、调试设置）；界面配色跟随系统浅色/深色，无独立主题选项
- **管理**：登录/注销、用户管理（需管理员权限）
- **烧录统计**：查看烧录统计结果（需添加烧录配置步骤）
- **扩展**：第一行显示 OCR 扩展当前状态，下面是安装/更新（.zip）、从文件夹安装、打开扩展目录、移除 OCR 扩展（详见 [OCR 扩展](#ocr-扩展单独发布)）
- **语言**：切换界面语言（英语 / 简体中文 / 繁体中文），当前语言项带勾选状态，选择后立即切换并保存到用户配置目录
- **帮助**：打开示例文件、使用说明、靶场（Playground）、**快捷键一览**、**日志**与关于
- **快捷键一览**（帮助菜单内）：按「通用 / 步骤表格 / 流程图 / 运行」四组列出快捷键——通用是新建/打开/保存/另存为与撤销恢复，步骤表格是复制剪切粘贴、删除与右键菜单，流程图是框选、多选、复制粘贴、删除、就地编辑、拖线、替换、环状菜单与 Ctrl+滚轮缩放；「运行」组只提示启动/停止热键（默认 Ctrl+Alt+F9 / Ctrl+Alt+F10，值存在 `settings.json` 的 Step 段）
- **日志**（帮助菜单内）：窗口分两个页签，都用文本方式直接看，一行一条记录，可选中复制、可一键复制当前页：
  - **执行日志**：`时间 | 线程 | 步骤 | 结果 | 耗时 | 详情`；支持按步骤文件筛选、关键字搜索、按日期范围筛选、分页，运行中写入新记录时自动刷新
  - **程序日志**：程序自身运行日志（打开工程失败、保存失败、图片落地失败等一般信息），按时间从新到旧显示；可按等级（DEBUG/INFO/WARN/ERROR/FATAL，选中即含更严重等级）与关键字筛选，可切换日期文件，页签可见时自动刷新；日志文件在程序目录 `logs\{日期}.log`，**固定保留 7 天**（启动时清理，不受执行日志保留天数设置影响）
- **退出**：关闭程序

**Step 设置中的「调试设置」**为运行时叠加显示，三项各自可设开关、颜色与显示时长（0.5~30 秒）：

| 叠加项 | 说明 | 默认值 |
|--------|------|--------|
| OCR 区域 | OCR 识别时在屏幕上标示识别区域 | 开启，颜色 `#00CC00`，2.0 秒 |
| 找到图像区域 | 识图步骤找到图像时标示匹配区域 | 关闭，颜色 `#0088FF`，2.0 秒 |
| 点击位置 | 执行点击时标示实际点击位置 | 关闭，颜色 `#FF4444`，1.5 秒 |

## 步骤类型详细说明

### 1. 点击识图 (ClickImage)

**功能：** 在屏幕上查找目标图片，找到后自动点击指定位置。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件（支持 png/jpg/jpeg），点击「选择」按钮选取，或点击「编辑」按钮打开图片编辑窗口裁剪区域和设置点击点 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1，值越高匹配越严格 | 0.85 |
| 高识别精度 | 勾选后除结构相似度外还要求颜色相似度达标，用于区分形状相同、只有颜色不同的画面 | 不勾选 |
| 颜色相似度阈值 | 启用高识别精度时的颜色相似度，范围 0~1 | 0.95 |
| 鼠标动作 | 找到图片后执行的鼠标动作序列（左键/右键/双击/长按/滚轮/拖拽），支持添加多个动作 | 左键单击 1 次 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒），超时未找到则步骤失败 | 3 |

**使用流程：**
1. 点击「选择」按钮选取目标图片（截取屏幕上某个按钮或图标的截图）
2. 点击「编辑」按钮打开图片编辑窗口，裁剪出精确的识别区域，并添加点击位置标记
3. 调整相似度阈值（建议 0.8~0.95，越高越严格）
4. 配置鼠标动作（可组合多种动作，如：左键点击 → 滚轮滚动）

---

### 2. 查找识图 (FindImage)

**功能：** 在屏幕上查找目标图片，仅判断是否找到（不点击），可用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1 | 0.85 |
| 高识别精度 | 勾选后除结构相似度外还要求颜色相似度达标 | 不勾选 |
| 颜色相似度阈值 | 启用高识别精度时的颜色相似度，范围 0~1 | 0.95 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒） | 3 |
| OCR 识别区域 | 找到图片后对该区域做 OCR（在图片编辑窗口「设置OCR区域」指定），结果可通过条件变量引用 | 未设置 |

**使用流程：**
1. 选择目标图片（同样支持「编辑」裁剪识别区域）
2. 设置相似度、查找间隔和超时参数
3. 步骤执行结果：找到为 `true`，未找到为 `false`
4. 可配合条件跳转实现条件分支
5. 需要读取目标附近的文字时，在图片编辑窗口用「设置OCR区域」框选范围，运行时会先匹配图片再做 OCR，结果写入 `Self_OCRText`

---

### 3. 获取文本 (GetInput)

**功能：** 从屏幕获取文本，支持 OCR 识别屏幕区域和 UI Automation 读取可选择文本两种模式。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 获取方式 | OCR（屏幕区域文字识别）/ ScreenText（读取 UI Automation 可选择文本） | OCR |
| OCR 区域 | OCR 方式下框选屏幕区域用于识别 | 未设置 |
| 文本获取点 | ScreenText 方式下的取点列表，可添加多个并按顺序逐个读取、结果按换行合并 | 空列表 |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 超时时间 | 单次获取的时间上限（秒），≤0 表示不限时；超时按执行超时处理 | 3 |

**文本获取点的坐标来源：**

| 来源 | 说明 |
|------|------|
| 绝对坐标 | 屏幕逻辑像素坐标，可用「选取坐标点」全屏点选 |
| 屏幕相对坐标 | 占主屏宽/高的百分比，换分辨率或换机器仍落在相对位置 |
| 图像相对定位 | 选一张原图并在图片编辑窗口裁剪、设置取点，运行时先匹配图像再按偏移取文本 |

**使用流程：**
1. 选择获取方式
2. OCR 方式：点击「选择区域」框选屏幕区域
3. ScreenText 方式：点「+」添加文本获取点，逐个选择坐标来源与位置
4. 点「测试」可预览获取结果，点击结果框可查看全文
5. 结果写入步骤执行结果，可用条件变量 `Self_OCRText` 被后续步骤引用；执行日志里 OCR 识别标注为 `[OCR:…]`、直接读取屏幕标注为 `[直接获取:…]`

---

### 4. 鼠标操作 (MouseAction)

**功能：** 在指定屏幕位置执行鼠标动作，不依赖图像识别。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 位置模式 | 绝对坐标（逻辑像素）/ 屏幕相对坐标（占主屏宽/高的百分比）/ 鼠标当前位置 | 绝对坐标 |
| 目标坐标 | 目标位置，可通过「选取坐标点」全屏点选；切换位置模式时坐标单位自动换算 | (0, 0) |
| 等待时间 | 执行前的等待时间（秒） | 0.1（新建时取设置中的「新建步骤默认等待时间」） |
| 动作列表 | 顺序执行的鼠标动作序列，每项含动作类型、执行次数、动作间隔（秒） | 左键单击 1 次，间隔 0.1 |

**支持的动作类型：**
- 左键单击、右键单击、双击
- 左键长按（按住时长 = 动作间隔）
- 滚轮上/下（执行次数 = 滚动格数）
- 拖拽（可编辑拖拽路径；相对坐标模式下路径点同样按百分比保存）

---

### 5. 输入文字 (TypeText)

**功能：** 模拟键盘输入一段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 需要输入的文本内容；右侧「▾」可改为引用其他步骤的结果 | - |
| 按键间隔 | 每个按键之间的延迟时间（秒），设为 0 则使用安全快速输入模式 | 0.05 |

**引用其他步骤的结果：** 点输入内容框右侧的「▾」，按「引用步骤 → 具体步骤 → 结果种类」选择——执行结果（PASS / FAIL）、OCR 文本、直接获取文本、扫码结果，或「用户输入」步骤里的字段值；引用后框上出现蓝色引用标签，运行时键入引用值（原固定文本保留，点标签即可清除恢复），被引用的步骤本次没执行过时键入空串。

---

### 6. 多次输入 (TypeTextMore)

**功能：** 按照前缀、中间、后缀的组合格式，批量循环输入多段文字。每次执行后自动递增标记了「递增」的文本片段。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 前缀/中间/后缀 | 组合输入的文本片段，各自可设置是否递增 | - |

**示例：** 前缀=`test`（递增）、中间=`_`、后缀=`@mail.com`，则依次输入 `test@mail.com`、`tesu@mail.com`...

---

### 7. 从文件输入 (TypeTextFromFile)

**功能：** 从文件（txt/csv/xlsx）中读取内容列表，每次执行输入一行，逐行递增。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 文件路径 | 支持的格式：`.txt`、`.csv`、`.xlsx` | - |

---

### 8. 弹出框 (Popup)

**功能：** 弹出自定义消息框，等待用户点击按钮，根据点击结果返回 true/false，可用于流程控制和人工干预。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 标题 | 弹窗标题 | - |
| 弹出文字 | 弹窗显示的文本内容（支持富文本编辑） | - |
| 字体/颜色 | 自定义弹窗文字的字体和颜色 | Arial 14号 黑色 |
| 图标 | None / Information / Warning / Error / Question | Information |
| 窗口样式 | 正常窗口 / 紧凑窗口 | 正常 |
| 窗口位置 | 屏幕坐标（可点选），-1 表示居中；可切换为屏幕相对坐标（占主屏宽/高的百分比） | 居中 |
| 背景不透明度 | 1~100% | 100% |
| 背景颜色 | 窗口背景颜色 | 白色 |
| 按钮 | 自定义弹窗按钮 | OK |
| 关闭模式 | 可复选项，任一项满足即关闭：点击按钮 / 超时自动关闭（默认 5 秒）/ 到达指定步骤关闭 | 点击按钮 |
| 同时存在个数 | 已经开着这么多个窗口时不再重复弹出，本步骤直接算通过（范围 1~20） | 1 |
| 弹出时暂停运行 | 勾选后弹窗一出来流程就暂停，关掉弹窗后自动继续 | 不勾 |
| 测试 | 按当前配置立刻弹一次，只用来预览效果，不影响运行结果 | - |

**返回值规则：**
- 点击 OK 或 Yes 按钮 → 返回 `true`
- 点击 No 或 Cancel 按钮 → 返回 `false`
- 点击右上角 ✕ 关闭 → 返回 `false`
- 超时自动关闭 → 返回弹窗默认按钮的值（默认 OK，即 `true`）

### 9. 窗口操作 (FocusWindow)

**功能：** 对指定窗口做「聚焦」（置于最前方并激活，最小化时先恢复）或「最小化」（收进任务栏）。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 操作 | 聚焦（置前激活，原来的行为）/ 最小化（把窗口收进任务栏） | 聚焦 |
| 指定窗口 | 从枚举列表中选择窗口标题（精确匹配优先）；本程序自己的窗口排在列表最前面 | - |
| 标题关键字 | 按关键字包含匹配（不区分大小写） | - |

**使用流程：**
1. 点击「枚举窗口」刷新当前可见窗口列表
2. 从下拉列表选择目标窗口，或输入标题关键字
3. 运行时查找并对目标窗口执行选定的操作（聚焦或最小化），未找到则步骤失败

> 没动过「操作」选项的旧工程仍按聚焦执行。

---

### 10. 统计信息 (Statistics)

**功能：** 执行时打开悬浮统计窗口，实时展示运行时统计信息。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 窗口标题 | 统计窗口标题 | Statistics |

### 14. 扫码 (ScanCode)

**功能：** 只做扫码——弹出扫码窗口等扫码枪或键盘输入条码，把条码作为本步骤的文本结果，供「上传 Acbel」步骤按「扫码结果」引用。本步骤**不连 Acbel 数据库、不调用任何 Acbel 函数**（验证网络、验证条码、写入基础资料都在「上传 Acbel」步骤里）。

**执行顺序：**

1. 按「等待时间」等待（可选）
2. 弹出扫码窗口等待扫码枪或键盘输入条码（回车 / Tab / 点「确定」返回；扫码枪成串输入后停顿约 350ms 自动确认，条码内的 `\r` `\n` `\t` 会被当作结束符去掉；取消或留空判失败）
3. 把条码（去掉首尾空白）记为本步骤的文本结果

**参数说明：** 除公共属性（等待时间、如果真 / 如果假、自定义条件等）外，还可以设置扫码窗口的**位置**（X / Y 留空或 -1 居中显示；可选「屏幕相对坐标」按主屏百分比保存，或用「选取坐标点」直接点屏幕取位）与**是否始终置顶**（勾选后弹窗不被别的窗口盖住）。旧版本工程里保存的「工单号字段名 / 站别字段名 / 工号字段名 / 线别字段名」已经不再使用，打开旧工程时自动忽略，不影响工程打开与运行。

**失败处理：** 取消扫码、条码为空、弹窗异常按失败处理并给出原因。

### 15. 上传 Acbel (AcbelUpload)

**功能：** 按 27 段字段规范组装上传资料，依次做条码校验（`CHKBAR_CODE`）、写入基础资料（`ACBEL_SET_BASIC_INFO`），再调用 `ACBEL_INSERT_DATA` 写入 Acbel MES。失败不抛异常，判本步骤失败并带上原因。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 仅校验、不写库 | 试运行：只按字段规范校验组装结果，不打开连接、不调条码校验、不调用上传 | 不勾选 |
| 上传前校验条码 | 上传前先用 `CHKBAR_CODE` 校验条码；关掉则跳过条码校验直接写基础资料并上传 | 勾选 |
| 条码来源 | 校验用的条码取哪一段的值（默认 4 INTERNAL_SR 单体条码）；把这一段引用扫码步骤的「扫码结果」即可自动跟着扫码走 | 4. INTERNAL_SR |
| 镭雕程式文件名 | 上传的第 3 个参数（独立的段号 0 行） | 空 |
| 必填字段 | 字段规范中标记为必填的段，直接列出 | 空 |
| 选填字段 | 其余选填段，收在「选填字段」折叠区内 | 空 |

**字段值来源：**

- **固定文本**：直接在该行输入框填写
- **引用其他步骤本次运行的结果**：点该行右侧的「▾」菜单选择
  - 普通步骤 → 执行结果（PASS / FAIL）、OCR 文本、直接获取文本、步骤开始时间、步骤结束时间
  - 用户输入步骤 → 该步骤下的某个字段名
  - 扫码步骤 → 扫码结果（条码）
- **引用程序运行时**：菜单 →「程序运行时 → 运行时日期/时间」，不依赖任何步骤。TEST_DATE 直接用它就能填程序运行当天的日期，START_TIME / END_TIME 用它就能填当前时刻。

**自动转成段要求的格式：** 取到的值（引用结果与固定文本都一样）会按目标段的字段类型归一后再组装、校验：

| 段类型 | 接受的写法 | 归一结果 |
|--------|-----------|----------|
| PASS / FAIL | `PASS` `FAIL` `true` `false` `1` `0` `OK` `NG` `真` `假` | `PASS` / `FAIL` |
| 时间（HHMMSS） | `140735` `14:07` `14:07:35` `14-07-35` `2026-11-19 14:07:35` | `140735` |
| 日期（YYYYMMDD） | `20261119` `2026-11-19` `2026/11/19` `2026-11-19 14:07:35` | `20261119` |
| 数值 | `0.1` `0,1` ` 0.1 ` | `0.1` |

> 时间类引用按 `HHmmss` 取值；开始时间 = 该步骤结束时间减去耗时，开始与结束可以分别引用不同步骤（见 `AcbelReferenceKind.StepStartTime` / `StepEndTime`）。

引用成功后该行显示蓝色引用标签（例如 `12. GetInput_1 · OCR 文本`、`用户输入 → 用户输入_1 / 工号`），点击标签即清除引用并恢复固定文本。

**执行顺序：**

1. 按字段规范校验组装结果（不通过直接判失败，不连数据库）
2. 勾选「仅校验、不写库」时到此结束
3. 首次上传时打开数据库连接并复用该连接
4. 校验条码：取「条码来源」段的当前值（默认 `INTERNAL_SR`），连同站别+工号（`STATION` + `UPD_USER`）调用 `CHKBAR_CODE`；勾掉「上传前校验条码」则跳过这一步；条码为空或校验不通过则不再写基础资料、不上传
5. 写入基础资料：工单号取 `MO_NO` 段、站别+工号取 `STATION` + `UPD_USER` 段（直接拼接）、线别取 `LINE_NAME` 段；失败则不再执行上传
6. 调用 `ACBEL_INSERT_DATA`；厂商返回内部异常（`2` 类别）时自动重试一次
7. 业务卡控（`0` 类别）失败时弹窗显示返回码与完整详情（条码校验与基础资料、上传各自弹窗，标题区分）

### 16. 多线程与信号

「多线程开始」「多线程区域结束」「发出信号」「接收信号」「中断」五个步骤配合使用：把一段步骤交给子线程执行，并在线程之间传递信号或打断主线程。

主流程跑完后会等待子线程把圈定的步骤跑完（点「停止」可立即中断）；子线程使用专用 STA 线程与消息泵，区域内的弹窗等窗口步骤可正常显示。

#### 16.1 多线程开始 (MultiThread)

**功能：** 到达本步骤时新建一个子线程执行「区域」内的步骤，主线程跳过该区域继续往下执行；每次到达本步骤各新建 1 个线程，达到线程个数上限后不再新建。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 线程个数 | 线程总数上限（≥1）；每次运行到本步骤新建 1 个，达到上限后不再新建 | 1 |
| 区域划定方式 | 按结束步骤选择 / 按「多线程区域结束」步骤 | 按结束步骤选择 |
| 结束步骤 | 仅在「按结束步骤选择」时可设，指定区域最后一个步骤（该步骤本身也在区域内）；不选表示到脚本末尾 | 到脚本末尾 |

> 区域不含「多线程开始」步骤本身；选择「按『多线程区域结束』步骤」方式时，取本步骤之后最近的区域结束标记，标记本身不执行。

#### 16.2 多线程区域结束 (MultiThreadEnd)

**功能：** 纯区域标记，本身不执行任何动作，用于与前面的「多线程开始」配对圈定区域。始终返回成功。

#### 16.3 发出信号 (SendSignal)

**功能：** 把配置的值发送到信号中心，同名信号覆盖为最新值。可在步骤之间（含主线程与子线程）传递数据。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 信号名 | 信号名称（区分大小写），不能为空，为空判失败 | 空 |
| 信号类型 | 布尔 / 整数 / 字符串，决定下方信号值的输入形式 | 布尔 |
| 信号值 | 布尔（勾选为 true）、整数或字符串，按信号类型显示对应输入项 | false / 0 / 空 |

#### 16.4 接收信号 (ReceiveSignal)

**功能：** 阻塞等待或立即读取指定信号；取到即消费（清除），收到的内容写入执行结果，可在条件判断中用「信号内容」变量使用。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 信号名 | 信号名称（区分大小写），不能为空 | 空 |
| 信号类型 | 布尔 / 整数 / 字符串，用于校验收到的值 | 布尔 |
| 阻塞等待 | 勾选后在此等待，直到收到信号或等待超时；不勾选则立刻读取（读不到判失败） | 勾选 |
| 等待超时 | 阻塞等待的时间上限（秒），0 表示不限时 | 10 |

> 类型校验不通过（例如期望布尔却收到其它文本）判失败，并给出「信号值类型不匹配」的提示。

#### 16.5 中断 (Interrupt)

**功能：** 打断主线程。子线程或主线程自己发出都可以，在主线程的**步骤边界**生效。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 动作 | 「跳到目标步骤」：主线程重定到目标步骤继续执行（目标在循环里就继续循环）；「结束本次运行」：立即结束整个流程，真正跳出主线程的循环 | 跳到目标步骤 |
| 中断后从该步骤开始执行 | 「跳到目标步骤」动作用：主线程重置到该步骤继续执行 | 未指定 |

**行为限制：**
- 「跳到目标步骤」未指定目标步骤判失败；「结束本次运行」不需要目标步骤
- 自动化未在运行中发出判失败
- 中断到达时会立刻中止当前正在执行的步骤（被打断的步骤不记失败），所以单步自循环、超时很长的步骤也能马上响应
- 多次中断只保留最新一次；同一轮运行里同时收到「结束本次运行」与跳转请求时，先结束运行

## 流程图视图

**功能：** 工具栏「表格 / 流程图」两个按钮切换编辑方式，两者共用同一份步骤数据，不用另开窗口——在一边改，另一边同步生效。流程图基于开源组件 Nodify（MIT 许可）。

**节点：** 每个步骤是一张卡片：序号与名称、备注、步骤类型与结果判断摘要；跳过不执行的步骤整体变灰，出错的步骤边框变红。右上角「记」控制本步骤是否记录执行日志，「锚」把节点钉住（自动整理时它保持原位，只能手动拖动）。双击名称可直接改名（回车确认、Esc 取消）。拖动卡片摆放位置，版面随工程保存。

**连线：** 卡片右侧是 S（顺序）、T（真）、F（假）出口，左侧是 I（入口）与 R（引用）出口。从 T / F 拖到目标卡片即设置若真 / 若假跳转；顺序落实线自动连到下一步；引用连线来自结果判断窗口里的「引用步骤」条件。颜色：顺序灰、真绿、假红、引用紫。

**显示与版面：** 「自动整理」点开是二级菜单——「默认」把节点只摆在矩形四条边上（口字形，左上 → 右上 → 右下 → 左下，步骤变多时把矩形撑大，不往中间填），「垂直流」顶部居中一路向下排成一列、连线沿两侧绕开卡片，两种都保持卡片样式不变，锚定的节点不动；「适应窗口」整体缩放，滚轮缩放、右键拖动平移；「焦点预览」只让从选中步骤走出去的连线保持原色（连进来的与其它线一起变淡，没选中时全部正常显示）；左下角全屏按钮铺满编辑区。

**快捷键：** Del 删除选中步骤。
------|------|
| 框选 / 多选 | 空白处按住左键拖框；Ctrl+左键逐个增删选中；Ctrl+A 全选 |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V（块内步骤之间的引用一并改到副本上） |
| 撤销 / 恢复 | Ctrl+Z / Ctrl+Y，按时间顺序回滚节点移动、连线改动、标题备注、日志开关、锚点与步骤增删 |
| 删除 | Del |
| 替换步骤 | 把一个节点拖到另一个上悬停 0.3 秒后松手 |
| 添加 / 右键菜单 | 右键节点：添加 / 替换为 / 删除 / 复制 / 清除跳转等；空白处按住右键 0.3 秒弹出环状菜单（添加 / 编辑） |
| 缩放 | 工具栏「适应窗口」或右侧百分比；画布上按住 Ctrl 滚轮直接缩放 |
| 全屏 | 画布左下角按钮：流程图铺满整个步骤编辑区（窗口内放大，不切换系统全屏），再点一次退出；全屏时详情面板悬浮在画布右侧，没选中节点时收起 |

**显示与版面：** 工具栏可切换折线 / 曲线 / 直线（直线模式从四条边中点挑最近的一对直连、不用锚点）；网络标签与真假标签可按住拖动（拖开后有虚线连回连线）；「焦点预览」打开后只让与选中步骤相连的连线保持原色、其余变淡（没选中时全部变淡）；「连线显示」三个开关（真 / 假 / 引用）勾选时该类连线全部显示、不勾时只显示与当前选中步骤相连的，顺序连线在横向 S 型下始终显示；工具栏左侧「排列方式」决定自动整理的排法——「横向 S 型」（默认）按窗口宽度蛇形排列（锚定节点不动、相邻步骤断开处自动换行），「竖直排列」把所有节点水平居中、自上而下紧密排成一列，此时不画顺序连线，真 / 假连线一律走节点右侧、引用连线走左侧（引用出口圆也挪到左边），切换方式后立即重排并把选择保存下来；节点位置、锚定状态与连线锚点随工程保存，重新打开与原版面一致。

## 通用属性

所有步骤都支持以下通用属性：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 启用 | 勾选/取消勾选是否执行该步骤（取消勾选则跳过执行） | 勾选 |
| 名称 | 步骤名称，用于标识与引用 | 自动生成（类型_序号；烧录配置用本地化默认名） |
| 描述 | 步骤描述信息，记录步骤用途 | 空 |
| 等待时间 | 执行前的等待延迟（秒） | 0.1（新建时取设置中的「新建步骤默认等待时间」） |
| 记录执行日志 | 勾选后将执行记录保存到数据库，可在执行日志中查看 | 不勾选 |
| 更多细节 | 仅在勾选「记录执行日志」后出现；开启后执行日志文本里「详情」部分才有内容 | 不勾选 |

### 跳转设置

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 如果真 | 步骤结果为 true 时跳转到指定步骤 | 无跳转 |
| 如果假 | 步骤结果为 false 时跳转到指定步骤 | 无跳转 |
| 次数上限（真 / 假各一） | 该分支最多跳多少次：`-1` 不限制、`0` 不跳转；达到上限后不再跳转、改走另一分支 | -1 |
| 超时（真 / 假各一，秒） | 从该分支第一次跳转开始计时，到点后不再跳转、改走另一分支；`0` 不限制 | 0 |
| 自引用上限 | 跳转到自身时的最大次数限制（-1=无限制, 0=禁止, >0=限制次数），达到上限时结果强制为 false | 10 |

**循环跳转保护：** 某一分支的次数或超时到点后，程序不再沿该分支跳转，而是改走另一分支；另一分支也没设跳转、或指回自己时，顺序执行下一步（等于跳出这个环继续往下），步骤上会记下「跳转次数已达上限，跳出循环执行下一步」。跳出后该分支的计数与计时清零，下次再进循环重新计算；两项都留默认（-1 / 0）时与以前一样无限跳转。

### 自定义条件判断

每个步骤支持自定义条件判断，替代默认的执行结果判断：

| 模式 | 说明 |
|------|------|
| 默认 | 使用步骤自身的执行结果 |
| 自定义 | 使用规则行组合判断 |

**条件变量：**

| 变量组 | 可选值 | 说明 |
|--------|--------|------|
| 常量 | 真 / 假 | 恒为真或恒为假 |
| 本步骤 | 执行结果、相似度、执行耗时、点击坐标、OCR 文本、弹窗结果、信号内容 | 取当前步骤本次执行的结果；「信号内容」仅「接收信号」步骤可用 |
| 引用步骤 | 同上（需指定引用步骤） | 取指定步骤最近一次执行的结果 |
| 引用步骤 → 本次被执行 | - | 引用步骤刚刚执行过时为 true（用于统计执行次数） |
| 引用步骤 → 用户输入字段 | 字段名 | 读取「用户输入」步骤指定字段的值（任何步骤都可添加） |

**识别文本提取：** 条件变量为「OCR 文本」时可先对文本做预处理——整段、按行读取（如 `1,3,5-8`）、从指定子串之后读取、从开头读取、从末尾读取；后三种可设读取长度（0=到末尾）与单位（字符/行）。

**运算符：**
- 比较：等于、不等于、大于、小于、大于等于、小于等于
- 字符串：包含、不包含、正则匹配、为空、不为空

**逻辑连接：** 多行条件支持 AND/OR 组合

## 图片编辑窗口

图片编辑窗口是烧录工具的核心辅助功能，用于精确设置图像识别区域和点击位置。在识图步骤（以及「获取文本」的图像相对取点）中点击「编辑」按钮即可打开。

### 图片裁剪

用于从原图中裁剪出精确的识别区域，提高匹配准确率。

**操作方法：**
1. 窗口打开后，主区域显示原图，图上有一个可拖动的裁剪框
2. 拖动裁剪框的边角控制点调整裁剪区域
3. 拖动裁剪框整体移动到目标位置
4. 点击底部「裁剪」按钮确认裁剪

> **提示：** 裁剪区域越小、越精确，识别速度越快、误匹配越少。建议只框选目标元素的关键特征区域。

### 点击点管理

点击点用于指定找到目标图片后，鼠标实际点击的位置。支持添加多个点击点。

**操作方法：**

| 操作 | 方法 |
|------|------|
| 添加点击点 | 顶部菜单 → 「添加点击点」 |
| 移动点击点 | 直接拖拽圆形标记到目标位置 |
| 显示/隐藏全部点击点 | 顶部菜单 → 「全部显示」/「全部隐藏」 |
| 删除单个点击点 | 右键点击点 → 「删除」 |
| 重置单个点击点 | 右键点击点 → 「重置」 |
| 隐藏单个点击点 | 右键点击点 → 「隐藏」 |
| 全部删除 | 顶部菜单 → 「全部删除」 |

**多点击点说明：**
- 每个点击点有编号标识
- 运行时按点击点列表顺序依次点击
- 适用于需要在同一界面多个位置点击的场景

### OCR 识别区域

供「查找识图」步骤在找到图片后对指定区域做文字识别。

| 操作 | 方法 |
|------|------|
| 设置 OCR 区域 | 顶部菜单 → 「设置OCR区域」，在原图上框选范围 |
| 清除 OCR 区域 | 顶部菜单 → 「清除OCR区域」 |

> 区域坐标相对原图像素保存；设置后该步骤的 OCR 识别组才会显示在详情面板中。
> 未安装 OCR 扩展时「设置OCR区域」为禁用状态，鼠标悬停显示安装说明。

### 保存与返回

| 按钮 | 功能 |
|------|------|
| 裁剪 | 确认裁剪区域，生成裁剪后的图片用于识别 |
| 保存 | 保存裁剪图片和点击点配置，关闭编辑窗口返回步骤列表 |
| 另存为 | 把当前裁剪结果另存为图片文件 |
| 返回 | 放弃修改，关闭编辑窗口 |

## OCR 扩展（单独发布）

OCR 引擎（Tesseract 5.5.2）、原生库（`tesseract55.dll` / `leptonica-1.85.0.dll`）与语言数据（`tessdata\`，约 100 MB）不随主程序打包，改由单独的 **OCR 扩展包** 提供：

| 项 | 说明 |
|----|------|
| 安装位置 | `<程序目录>\extensions\Ocr\`（扩展包里就带这个 `Ocr` 文件夹，整个复制过去即可） |
| 生效判断 | 「帮助 → 日志 → 程序日志」出现 `OCR extension loaded: Tesseract OCR …` 即已加载 |
| 未安装时 | 「获取文本」的输入方式里没有「OCR 识别」（旧名「获取输入」）；图像编辑窗口的「设置OCR区域」禁用并提示安装方法；已设置过 OCR 区域的图像步骤照常匹配图像、跳过文字识别并提示原因；其余功能不受影响 |
| 卸载 | 关闭程序后删除 `extensions\Ocr` 文件夹 |
| 版本 | 扩展包文件名带主程序版本号，与主体包一一对应 |

**安装方式（菜单）：** 程序内置「扩展」菜单，不用手工拷贝目录：

| 菜单项 | 行为 |
|--------|------|
| 扩展 → 安装/更新 OCR 扩展包（.zip）… | 选扩展包 zip → 自动检查（必备文件、x64 位数、入口程序集里确有扩展入口）→ 装到 `extensions\Ocr` → **直接重启程序**生效 |
| 扩展 → 从文件夹安装 OCR 扩展… | 同上，来源换成已解压的文件夹（选含 `Ocr` 的那一层或 `Ocr` 本身都行） |
| 扩展 → 打开扩展目录 | 定位 `extensions\Ocr`（还没装时打开 `extensions` 并自动创建） |
| 扩展 → 移除 OCR 扩展 | 确认后删除 `extensions\Ocr` 并重启程序 |
| 扩展 → 第一行状态 | 显示 `OCR 扩展：已加载（Tesseract OCR …）` 或 `未安装，OCR 功能已禁用` |

> 安装前的检查不通过时会列出具体原因（缺 `tessdata`、原生库不是 x64、入口程序集里没有 `IOcrExtensionFactory` 实现等），不会覆盖当前能用的扩展；安装过程先备份旧扩展，复制失败自动回滚。正在运行步骤时不允许安装/移除（需先停止），未保存的修改会先询问。

**打包脚本：**

| 脚本 | 作用 |
|------|------|
| `tools\pack-release.ps1` | 只打主体包 `AutoShaoLu_<版本>\`；脚本会校验主体包里没有混入 OCR 运行时文件 |
| `tools\pack-ocr-extension.ps1` | 打 OCR 扩展包 `AutoShaoLu_<版本>_OcrExtension\`（内含 `Ocr\` 与「安装说明.txt」），加 `-Zip` 额外产出压缩包 |
| `tools\install-ocr-extension.ps1` | 本地调试用：把扩展装到 `ShaoLu\bin\x64\<配置>\extensions\Ocr`，`-Uninstall` 移除 |

## 数据存储位置

用户数据统一放在 `%APPDATA%\AutoShaoLu\` 下；OCR 扩展（引擎 + 语言数据）单独安装到程序目录的 `extensions\Ocr\`。

| 数据类型 | 位置 |
|----------|------|
| 步骤文件 | 用户选择的位置（.autostep 打包格式，裁剪图、原图与烧录判据模板随包保存） |
| 用户账号 | `%APPDATA%\AutoShaoLu\users.db`（SQLite） |
| 程序设置 | `%APPDATA%\AutoShaoLu\settings.json` |
| 烧录记录 | `%APPDATA%\AutoShaoLu\burn_in.db`（SQLite） |
| 烧录配置 | `%APPDATA%\AutoShaoLu\burn_in_config.json` |
| 烧录上次会话 | `%APPDATA%\AutoShaoLu\burn_in_last_session.json` |
| 烧录截图 | `%APPDATA%\AutoShaoLu\screenshots\{工令}\yyyyMMdd_HHmmss_fff.png`（保存目录可在烧录配置中改） |
| 最近文件 | `%APPDATA%\AutoShaoLu\recent_files.json`（最多保留 10 条） |
| 执行日志 | `%APPDATA%\AutoShaoLu\execution_log.db`（SQLite） |
| 程序日志 | 程序目录 `logs\{日期}.log`（按天分文件，固定保留 7 天，启动时清理） |
| 界面语言 | `%APPDATA%\AutoShaoLu\current_language.txt` |
| OCR 扩展 | 程序目录 `extensions\Ocr\`（引擎、原生库与 `tessdata\` 语言数据；未安装时 OCR 功能禁用） |
| 工程解压工作目录 | `%TEMP%\AutoShaoLu\steps\{工程名}-{随机}`（打开 `.autostep` 时解压到这里，程序退出删除，启动时清理上次残留） |
| 原图临时目录 | `%TEMP%\AutoShaoLu\source_images\`（截图/选择的原图在保存前放这里） |

**执行日志分表：** 日志按步骤文件分表保存在同一个 `execution_log.db` 内，表名由步骤文件名派生（保留 ASCII 字母数字，其余字符转下划线，再附 8 位哈希防碰撞，前缀 `StepLog_`；未保存的工程记为 `unsaved`）。未分表的历史数据仍留在主表 `StepExecutionLog` 中。

## 技术栈

- **框架：** .NET Framework 4.8 + WPF（x64）
- **架构：** CommunityToolkit.Mvvm（MVVM）；System.Reactive（图像编辑工具的截图与全局快捷键）
- **OCR：** 可选扩展 `extensions\Ocr`（TesseractOCR 5.5.2 + `tessdata\`，单独打包发布；未安装时 OCR 相关功能自动禁用）
- **图像识别：** OpenCvSharp4（含 Windows 运行时）
- **屏幕文本读取：** UIAutomationClient（读取可选择文本）
- **数据库：** SQLite（FreeSql.Provider.Sqlite）
- **本地化：** WPFLocalizeExtension（简体中文 / 繁体中文 / 英文）
- **日志：** NLog
- **表格导入导出：** EPPlus（xlsx）
- **文档预览：** Microsoft.Web.WebView2（「帮助 → 使用文档」用内置 WebView2 窗口打开 HTML 版说明书，没有 HTML 时打开 PDF）
- **说明书构建：** `tools\build-manual.ps1`：pandoc 把仓库根目录的 `使用说明书.md` 渲染成自包含 HTML（图片内嵌），再用 Edge 无头打印成 PDF，两个成品输出到 `ShaoLu\Docs\`；`tools\manual.css` 提供排版样式
- **模拟输入：** InputSimulator
- **文本编码识别：** UTF.Unknown
- **JSON：** System.Text.Json
- **UI 组件：** WPFDevelopers
- **Acbel 桥接进程：** 独立 x86 工程 `AcbelBridge\`，独占加载 32 位原生 `Acbel_Chroma_Test.dll`；x64 主程序通过子进程 stdin/stdout 的行协议调用它（一行一请求/一行一响应，参数 Base64 编码）。另提供人工调试入口：`AcbelBridge.exe --console [--allow-write]`（双击默认进控制台，`help` 看命令表；写 MES 的命令需显式加 `--allow-write`；参数为管道调用时自动走协议，可加 `--protocol` 强制）
- **解决方案工程：** `ShaoLu.slnx` 含 ShaoLu（主程序，x64）、AcbelBridge（x86 桥接进程）、NUnitTest（NUnit 测试工程）
