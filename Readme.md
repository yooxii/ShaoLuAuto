# 烧录 (ShaoLu)

一款基于 WPF 的桌面自动化工具，通过图像识别和模拟输入实现 GUI 自动化操作。

---

## 快速开始

1. 启动程序后，在主界面通过步骤列表添加自动化步骤
2. 每个步骤可设置名称、描述、启用/禁用、等待时间、条件跳转等通用属性
3. 点击步骤旁的「编辑」按钮可展开详细参数配置
4. 配置完成后点击「运行」开始执行自动化流程
5. 快捷键：Ctrl+Alt+F9 运行；Ctrl+Alt+F10 停止

---

## 步骤类型详细说明

### 1. 点击识图 (ClickImage)

**功能：** 在屏幕上查找目标图片，找到后自动点击指定位置。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件（支持 png/jpg/jpeg），点击「选择」按钮选取，或点击「编辑」按钮打开图片编辑窗口裁剪区域和设置点击点 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1，值越高匹配越严格 | 0.85 |
| 点击次数 | 找到图片后的点击次数 | 1 |
| 点击间隔 | 多次点击时，每次点击之间的间隔时间（秒） | 0.1 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒），超时未找到则步骤失败 | 3 |

**使用流程：**
1. 点击「选择」按钮选取目标图片（截取屏幕上某个按钮或图标的截图）
2. 点击「编辑」按钮打开图片编辑窗口，裁剪出精确的识别区域，并添加点击位置标记
3. 调整相似度阈值（建议 0.8~0.95，越高越严格）
4. 设置点击次数和间隔

---

### 2. 查找识图 (FindImage)

**功能：** 在屏幕上查找目标图片，仅判断是否找到（不点击），可用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1 | 0.85 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒） | 3 |

**使用流程：**
1. 选择目标图片（同样支持「编辑」裁剪识别区域）
2. 设置相似度和超时参数
3. 步骤执行结果：找到为 `true`，未找到为 `false`
4. 可配合「如果真/如果假」跳转实现条件分支

---

### 3. 多图点击 (ClickImages)

**功能：** 依次在屏幕上查找多张目标图片，按列表顺序逐一查找并点击。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 图片列表 | 通过 + / - 按钮添加或移除多张目标图片，每张图片可独立设置相似度和点击区域 | - |
| 点击次数 | 找到每张图片后的点击次数 | 1 |
| 点击间隔 | 多次点击之间的间隔（秒） | 0.1 |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 超时时间 | 每张图片的查找超时时间（秒） | 3 |

**使用流程：**
1. 点击 **+** 按钮添加多张目标图片
2. 分别选择每张图片，点击「编辑」可裁剪区域和设置点击点
3. 运行时按列表顺序依次查找并点击

---

### 4. 多图查找 (FindImages)

**功能：** 同时在屏幕上查找多张目标图片，判断是否全部找到（不点击），用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 图片列表 | 通过 + / - 按钮添加或移除多张目标图片 | - |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找的最大超时时间（秒） | 3 |

**使用流程：**
1. 添加多张需要查找的目标图片
2. 设置查找参数
3. 所有图片都找到时结果为 `true`，任一张未找到则为 `false`

---

### 5. 输入文字 (TypeText)

**功能：** 模拟键盘输入一段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 需要输入的文本内容 | - |
| 按键间隔 | 每个按键之间的延迟时间（秒），设为 0 则使用安全快速输入模式 | 0.05 |

**使用流程：**
1. 在「输入内容」框中填写要输入的文字
2. 调整按键间隔（中文输入建议 0.05 以上，纯英文数字可适当减小）
3. 运行时会在当前焦点位置逐字输入

> **提示：** 按键间隔设为 0 时使用 `TypeTextSafe` 模式，兼容性更好但速度可能较慢。

---

### 6. 多次输入 (TypeTextMore)

**功能：** 按照前缀、中间、后缀的组合格式，批量循环输入多段文字。每次执行后自动递增标记了「递增」的文本片段。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒），设为 0 使用安全模式 | 0.01 |
| 前缀 | 组合输入的前缀文本片段 | - |
| 前缀递增 | 是否每次执行后自动递增前缀（如 a→b→c，1→2→3） | 否 |
| 中间 | 组合输入的中间文本片段 | - |
| 中间递增 | 是否每次执行后自动递增中间片段 | 否 |
| 后缀 | 组合输入的后缀文本片段 | - |
| 后缀递增 | 是否每次执行后自动递增后缀片段 | 否 |

**使用流程：**
1. 将输入内容拆分为「前缀 + 中间 + 后缀」三部分
2. 勾选需要自动递增的部分（例如用户名后缀需要编号递增）
3. 每次执行步骤时，标记递增的片段会自动递增（如 `user001` → `user002` → ...）
4. 实际输入内容 = 前缀 + 中间 + 后缀

**示例：** 前缀=`test`（递增）、中间=`_`、后缀=`@mail.com`，则依次输入 `a@mail.com`、`b@mail.com`、`c@mail.com`...

---

### 7. 从文件输入 (TypeTextFromFile)

**功能：** 从文件（txt/csv/xlsx）中读取内容列表，每次执行输入一行，逐行递增。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 文件路径 | 支持的格式：`.txt`、`.csv`、`.xlsx` | - |

**使用流程：**
1. 点击「选择」按钮加载数据文件
2. 支持的文件格式：
   - **txt/csv**：按换行符、逗号、分号、Tab、`|` 等分隔符拆分内容
   - **xlsx**：读取第一个工作表第一列的每行数据
3. 加载后会在列表中显示所有待输入内容
4. 每次执行步骤时，自动输入下一行内容
5. 所有内容输入完毕后步骤报错

> **提示：** 也可通过 + / - 按钮手动添加或移除列表中的内容条目。

---

### 8. 弹出框 (Popup)

**功能：** 弹出自定义消息框，等待用户点击按钮，根据点击结果返回 true/false，可用于流程控制和人工干预。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 标题 | 弹窗标题 | - |
| 弹出文字 | 弹窗显示的文本内容 | - |
| 字体 | 点击字体按钮可弹出系统字体选择器，自定义弹窗文字的字体 | Arial 14号 |
| 颜色 | 点击颜色按钮可弹出颜色选择器，自定义文字颜色 | 黑色 |
| 弹窗类型 | Information / Warning / Error / Question（影响图标显示） | Information |
| 按钮 | 自定义弹窗按钮，通过 + / - 添加或移除按钮 | OK |

**使用流程：**
1. 设置弹窗标题和内容
2. 选择弹窗类型（影响图标显示）
3. 可选：自定义字体和颜色
4. 自定义按钮文本和返回值
5. 运行时弹出对话框，用户点击按钮后根据返回值决定步骤结果（true/false）
6. 可配合条件跳转实现人工确认环节

**示例：** 创建一个 Question 类型弹窗，按钮设为「是」(返回 true) 和「否」(返回 false)，配合「如果真」跳转到继续执行，「如果假」跳转到结束。

## 通用属性

所有步骤都支持以下通用属性：

| 属性 | 说明 |
|------|------|
| 启用 | 勾选/取消勾选是否启用该步骤（取消勾选则跳过执行） |
| 名称 | 步骤名称，用于标识 |
| 描述 | 步骤描述信息，记录步骤用途 |
| 等待时间 | 执行前的等待延迟（秒），所有步骤都支持 |
| 如果真 | 步骤结果为 true 时跳转到指定行号执行 |
| 如果假 | 步骤结果为 false 时跳转到指定行号执行 |

**流程控制说明：**
- 「如果真」和「如果假」配合使用可实现条件分支、循环等复杂逻辑
- 行号从 0 开始，对应步骤列表中的序号
- 不设置跳转时，步骤按顺序依次执行

## 图片编辑窗口

图片编辑窗口是烧录工具的核心辅助功能，用于精确设置图像识别区域和点击位置。在识图步骤中点击「编辑」按钮即可打开。

### 窗口布局

编辑窗口分为三个区域：

1. **顶部菜单栏** — 点击点相关操作
2. **中间主区域** — 图片裁剪区 + 点击点标记 + 预览区
3. **底部按钮栏** — 裁剪 / 保存 / 返回

### 图片裁剪

用于从原图中裁剪出精确的识别区域，提高匹配准确率。

**操作方法：**
1. 窗口打开后，主区域显示原图，图上有一个可拖动的裁剪框
2. 拖动裁剪框的边角控制点调整裁剪区域
3. 拖动裁剪框整体移动到目标位置
4. 点击底部「裁剪」按钮确认裁剪，裁剪结果会在下方预览区显示

> **提示：** 裁剪区域越小、越精确，识别速度越快、误匹配越少。建议只框选目标元素的关键特征区域。

### 点击点管理

点击点用于指定找到目标图片后，鼠标实际点击的位置。支持添加多个点击点。

**操作方法：**

| 操作 | 方法 |
|------|------|
| 添加点击点 | 顶部菜单 → 「添加点击点」，在图片中心位置添加一个红色圆形标记 |
| 移动点击点 | 直接拖拽红色圆形标记到目标位置 |
| 查看坐标 | 鼠标悬停在点击点上，ToolTip 显示绝对坐标 |
| 重置点击点 | 右键点击点 → 「重置」，回到图片中心位置 |
| 删除单个点击点 | 右键点击点 → 「删除」 |
| 显示/隐藏点击点 | 右键点击点 → 「隐藏/显示」 |
| 全部显示 | 顶部菜单 → 「全部显示」 |
| 全部隐藏 | 顶部菜单 → 「全部隐藏」 |
| 全部删除 | 顶部菜单 → 「全部删除」 |

**多点击点说明：**
- 每个点击点有编号标识（右上角数字标签）
- 运行时按点击点列表顺序依次点击
- 适用于需要在同一界面多个位置点击的场景

### 保存与返回

| 按钮 | 功能 |
|------|------|
| 裁剪 | 确认裁剪区域，生成裁剪后的图片用于识别 |
| 保存 | 保存裁剪图片和点击点配置，关闭编辑窗口返回步骤列表 |
| 返回 | 放弃修改，关闭编辑窗口 |

> **注意：** 保存时必须同时有裁剪图片和至少一个点击点，否则会提示错误。
