# AutoShaoLu 0.6.8.2611（预览版）

自动化烧录工具（ShaoLu）0.6 预览版。

## 本次新增

- **用户输入步骤**：可在步骤列表新增，打开工程 / 开始运行前弹窗让使用者填写字段；字段可在详情面板增删改（文本、数字、日期、密码、下拉），值随工程保存、下次打开预填；上传Acbel 的字段可按「用户输入 → 步骤 → 字段」引用，条件判断也新增「用户输入字段」变量。
- **用户输入字段可冻结**：详情面板可勾选「冻结」，字段第一次确认填写后锁定，未登录时只读，尝试修改会提示登录；登录后自动解锁。
- **步骤详情分段滚动**：详情面板里每个设置段各自带一条 6px 细横向滚动条，过宽的表格不再挤压其他控件；段内不再拦截鼠标滚轮，整页竖向滚动更顺畅。

## 0.6 预览版已包含

- 多线程步骤、跨线程信号与中断、多线程区域折叠、子线程统计与执行记录展示。
- 上传Acbel 步骤（ACBEL_INSERT_DATA）、发布包随带 AcbelBridge、自动补齐 D 盘运行环境。
- 屏幕相对坐标、图像识别颜色（高识别精度）、步骤多选批量移动。
- 审查修复：保存原子化与备份、图片与烧录模板随包、损坏工程不毁目录、OCR 区域清空不崩、多屏坐标、停止后可立即重跑、异常后复位、删除步骤引用清理、统计与日志落库、CSV 注入防护、用户管理权限、设置/语言文件 AppData 原子写等。

## 运行环境

- Windows 10 / 11 x64
- .NET Framework 4.8
- Microsoft Edge WebView2 Runtime（查看 PDF 说明书时需要）

## 包内容

- `AutoShaoLu_0.6.8.2611.zip`：程序与运行时依赖（含 `AcbelBridge.exe`、`Acbel_Chroma_Test.dll`、`tessdata`、`Docs`、`Examples`）。解压后直接运行 `ShaoLu.exe`。
- `AutoShaoLu_Source_0.6.8.2611.zip`：必要源码（解决方案、主程序/测试/桥接工程、`Reference` 编译依赖、构建脚本），不含 `bin/obj`、`tessdata`、`Docs`、`Examples` 等运行时资源。

> 预览版：功能与接口仍可能调整；生产使用前请先在测试机验证。
