- 每个测试类以 [TestFixture] 标记，测试方法用 [Test] 标记，并通过 Assert.That(..., Is.EqualTo(...)) / Is.True / Is.Null 等 Fluent 断言风格编写。
- 测试类内部使用嵌套 class + #region 对同一被测类型的不同行为进行分组（如 TypeTextStepTests、TypeTextMoreStepTests、EmptyStepTests 等），保持一个被测类型对应一个文件。
- 需要共享状态的测试使用 [SetUp] 初始化字段（如 _context、_currentResult、_converter），需要清理资源的测试使用 [TearDown] 释放（如 StepsFileTests 的临时目录）。
- 对异常行为的测试统一使用 Assert.Throws<ExceptionType>((TestDelegate)(() => ...)) 形式包裹委托调用。
- Clone 方法的测试遵循固定模式：先构造 original → Clone() 得到 clone → 修改 clone → 断言 original 未被影响，验证深拷贝语义。
