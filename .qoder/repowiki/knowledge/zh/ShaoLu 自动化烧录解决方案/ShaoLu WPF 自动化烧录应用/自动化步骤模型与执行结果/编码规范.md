- 枚举采用分组编号方式组织相关类型（如 ClickImage/FindImage 为默认段，ClickImages/FindImages 从 100 开始，GetInput/MouseAction/Statistics 从 200 开始，Popup 从 1000 开始）。
- MVVM 属性统一通过 CommunityToolkit.Mvvm 的 SetProperty(ref _field, value) 设置，并在必要时触发 OnPropertyChanged 通知 UI 刷新。
- 需要排除序列化的运行时字段使用 [JsonIgnore] 标注，而需要自定义 JSON 键名的字段使用 [JsonPropertyName("...")] 标注。
- 数据库实体统一使用 FreeSql.DataAnnotations 的 [Table(Name = "...")] 和 [Column(...)] 特性声明表名与列约束。
