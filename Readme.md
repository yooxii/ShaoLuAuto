# 烧录 (ShaoLu)

一款基于 WPF 的桌面自动化工具，通过图像识别、OCR 文字识别和模拟输入实现 GUI 自动化操作。

---

## 快速开始

1. 启动程序后，在主界面工具栏的「步骤」组添加自动化步骤
2. 每个步骤可设置名称、描述、启用/禁用、等待时间、条件跳转等通用属性
3. 在步骤列表中选中某个步骤，右侧「步骤详情」面板即显示它的参数配置
4. 配置完成后点击「运行」开始执行自动化流程
5. 运行/停止默认热键为 Ctrl+Alt+F9 / Ctrl+Alt+F10（全局生效；热键值保存在 `settings.json` 的 Step 段，界面不提供修改入口）
6. 新建、保存、另存为以及「编辑」「步骤」两组工具栏需要先登录（「管理 → 登录」）才可用

## 主界面功能

### 菜单栏

菜单依次为：文件 / 编辑 / 设置 / 管理 / 烧录统计 / 语言 / 帮助 / 退出。

### 文件菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 新建 | Ctrl+N | 清空当前步骤列表（需登录） |
| 打开 | Ctrl+O | 打开步骤文件（支持 .autostep 和旧版 .json），不需要登录 |
| 保存 | Ctrl+S | 保存步骤文件（需登录） |
| 另存为 | Ctrl+Shift+S | 另存为新文件（需登录） |
| 最近打开的文件 | - | 展示最近打开的 10 个文件，点击即可直接打开 |

### 编辑菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 撤销 / 恢复 | Ctrl+Z / Ctrl+Y | 步骤列表整体的撤销与恢复（最多保留 50 步） |
| 撤销本步骤编辑 / 恢复本步骤编辑 | - | 只回滚当前选中步骤内部的参数修改 |
| 上移 / 下移 | - | 移动选中步骤，支持多选批量移动 |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V | 步骤的复制、剪切与粘贴 |
| 删除 | - | 删除选中步骤 |
| 添加步骤 | - | 单独一段（与其他项隔开），列出全部步骤类型，添加位置与工具栏一致：插在当前选中步骤之后 |

### 运行控制

- **运行**：开始执行自动化流程（默认热键 Ctrl+Alt+F9）
- **暂停/继续**：在步骤间暂停执行，可恢复继续
- **停止**：终止当前运行（默认热键 Ctrl+Alt+F10）

### 工具栏分组

工具栏分为运行、编辑、步骤三组：

- **运行组**（常显）：运行 / 暂停（继续）/ 停止
- **编辑组**：刷新、撤销、恢复、上移、下移、复制、剪切、粘贴、删除
- **步骤组**：下拉按钮按类型分组——识图与文字（识图、查找识图、文字、文字(多)、文字(从文件)、鼠标操作）、获取文本（获取文本、统计信息、烧录配置、窗口聚焦、空步骤）、多线程（5 个步骤）、弹出窗口、扫码（扫码、上传 Acbel）、用户输入

「编辑」「步骤」两组可点组名展开/收起（▸/▾ 指示状态）。宽度足够时两组都展开；放不下时自动折叠编辑组，此情形下手动展开其中一组会收起另一组。

### 状态栏与窗口标题

- **窗口标题**：程序名 + 当前脚本名，未保存时显示「未保存」
- **状态栏左侧**：当前正在执行的步骤名（未运行时为空）
- **状态栏右侧**：运行状态（未运行 / 运行中 / 已暂停）
- **默认窗口尺寸**：打开时取主屏 60% 宽 × 60% 高（下限 800 × 500，并留出屏幕边距）
- **多线程区域**：区域内的步骤连同「多线程开始」「多线程区域结束」两行统一用淡蓝色背景（`#FFE8F3FF`），出错时仍为红色；可在开始行上折叠/展开（详见步骤类型第 16 节）

### 其他菜单

- **设置**：App 设置（字体、执行日志保留天数，默认 30 天）与 Step 设置（运行行为、新建步骤默认参数、调试设置）；界面配色跟随系统浅色/深色，无独立主题选项
- **管理**：登录/注销、用户管理（需管理员权限）
- **烧录统计**：查看烧录统计结果（需添加烧录配置步骤）
- **语言**：切换界面语言（英语 / 简体中文 / 繁体中文），当前语言项带勾选状态，选择后立即切换并保存到用户配置目录
- **帮助**：打开示例文件、使用说明、靶场（Playground）、**日志**与关于
- **日志**（帮助菜单内）：窗口分两个页签，都用文本方式直接看，一行一条记录，可选中复制、可一键复制当前页：
  - **执行日志**：`时间 | 线程 | 步骤 | 结果 | 耗时 | 详情`；支持按步骤文件筛选、关键字搜索、按日期范围筛选、分页，运行中写入新记录时自动刷新
  - **程序日志**：程序自身运行日志（打开工程失败、保存失败、图片落地失败等一般信息），按时间从新到旧显示；可按等级（DEBUG/INFO/WARN/ERROR/FATAL，选中即含更严重等级）与关键字筛选，可切换日期文件，页签可见时自动刷新；日志文件在程序目录 `logs\{日期}.log`，**固定保留 7 天**（启动时清理，不受执行日志保留天数设置影响）
- **退出**：关闭程序

**Step 设置中的「调试设置」**为运行时叠加显示，三项各自可设开关、颜色与显示时长（0.5~30 秒）：

| 叠加项 | 说明 | 默认值 |
|--------|------|--------|
| OCR 区域 | OCR 识别时在屏幕上标示识别区域 | 开启，颜色 `#00CC00`，2.0 秒 |
| 找到图像区域 | 识图步骤找到图像时标示匹配区域 | 关闭，颜色 `#0088FF`，2.0 秒 |
| 点击位置 | 执行点击时标示实际点击位置 | 关闭，颜色 `#FF4444`，1.5 秒 |

## 步骤类型详细说明

### 1. 点击识图 (ClickImage)

**功能：** 在屏幕上查找目标图片，找到后自动点击指定位置。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件（支持 png/jpg/jpeg），点击「选择」按钮选取，或点击「编辑」按钮打开图片编辑窗口裁剪区域和设置点击点 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1，值越高匹配越严格 | 0.85 |
| 高识别精度 | 勾选后除结构相似度外还要求颜色相似度达标，用于区分形状相同、只有颜色不同的画面 | 不勾选 |
| 颜色相似度阈值 | 启用高识别精度时的颜色相似度，范围 0~1 | 0.95 |
| 鼠标动作 | 找到图片后执行的鼠标动作序列（左键/右键/双击/长按/滚轮/拖拽），支持添加多个动作 | 左键单击 1 次 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒），超时未找到则步骤失败 | 3 |

**使用流程：**
1. 点击「选择」按钮选取目标图片（截取屏幕上某个按钮或图标的截图）
2. 点击「编辑」按钮打开图片编辑窗口，裁剪出精确的识别区域，并添加点击位置标记
3. 调整相似度阈值（建议 0.8~0.95，越高越严格）
4. 配置鼠标动作（可组合多种动作，如：左键点击 → 滚轮滚动）

---

### 2. 查找识图 (FindImage)

**功能：** 在屏幕上查找目标图片，仅判断是否找到（不点击），可用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1 | 0.85 |
| 高识别精度 | 勾选后除结构相似度外还要求颜色相似度达标 | 不勾选 |
| 颜色相似度阈值 | 启用高识别精度时的颜色相似度，范围 0~1 | 0.95 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒） | 3 |
| OCR 识别区域 | 找到图片后对该区域做 OCR（在图片编辑窗口「设置OCR区域」指定），结果可通过条件变量引用 | 未设置 |

**使用流程：**
1. 选择目标图片（同样支持「编辑」裁剪识别区域）
2. 设置相似度、查找间隔和超时参数
3. 步骤执行结果：找到为 `true`，未找到为 `false`
4. 可配合条件跳转实现条件分支
5. 需要读取目标附近的文字时，在图片编辑窗口用「设置OCR区域」框选范围，运行时会先匹配图片再做 OCR，结果写入 `Self_OCRText`

---

### 3. 获取文本 (GetInput)

**功能：** 从屏幕获取文本，支持 OCR 识别屏幕区域和 UI Automation 读取可选择文本两种模式。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 获取方式 | OCR（屏幕区域文字识别）/ ScreenText（读取 UI Automation 可选择文本） | OCR |
| OCR 区域 | OCR 方式下框选屏幕区域用于识别 | 未设置 |
| 文本获取点 | ScreenText 方式下的取点列表，可添加多个并按顺序逐个读取、结果按换行合并 | 空列表 |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 超时时间 | 单次获取的时间上限（秒），≤0 表示不限时；超时按执行超时处理 | 3 |

**文本获取点的坐标来源：**

| 来源 | 说明 |
|------|------|
| 绝对坐标 | 屏幕逻辑像素坐标，可用「选取坐标点」全屏点选 |
| 屏幕相对坐标 | 占主屏宽/高的百分比，换分辨率或换机器仍落在相对位置 |
| 图像相对定位 | 选一张原图并在图片编辑窗口裁剪、设置取点，运行时先匹配图像再按偏移取文本 |

**使用流程：**
1. 选择获取方式
2. OCR 方式：点击「选择区域」框选屏幕区域
3. ScreenText 方式：点「+」添加文本获取点，逐个选择坐标来源与位置
4. 点「测试」可预览获取结果，点击结果框可查看全文
5. 结果写入步骤执行结果，可用条件变量 `Self_OCRText` 被后续步骤引用；执行记录里 OCR 识别标注为 `[OCR:…]`、直接读取屏幕标注为 `[直接获取:…]`

---

### 4. 鼠标操作 (MouseAction)

**功能：** 在指定屏幕位置执行鼠标动作，不依赖图像识别。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 位置模式 | 绝对坐标（逻辑像素）/ 屏幕相对坐标（占主屏宽/高的百分比）/ 鼠标当前位置 | 绝对坐标 |
| 目标坐标 | 目标位置，可通过「选取坐标点」全屏点选；切换位置模式时坐标单位自动换算 | (0, 0) |
| 等待时间 | 执行前的等待时间（秒） | 0.1（新建时取设置中的「新建步骤默认等待时间」） |
| 动作列表 | 顺序执行的鼠标动作序列，每项含动作类型、执行次数、动作间隔（秒） | 左键单击 1 次，间隔 0.1 |

**支持的动作类型：**
- 左键单击、右键单击、双击
- 左键长按（按住时长 = 动作间隔）
- 滚轮上/下（执行次数 = 滚动格数）
- 拖拽（可编辑拖拽路径；相对坐标模式下路径点同样按百分比保存）

---

### 5. 输入文字 (TypeText)

**功能：** 模拟键盘输入一段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 需要输入的文本内容 | - |
| 按键间隔 | 每个按键之间的延迟时间（秒），设为 0 则使用安全快速输入模式 | 0.05 |

---

### 6. 多次输入 (TypeTextMore)

**功能：** 按照前缀、中间、后缀的组合格式，批量循环输入多段文字。每次执行后自动递增标记了「递增」的文本片段。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 前缀/中间/后缀 | 组合输入的文本片段，各自可设置是否递增 | - |

**示例：** 前缀=`test`（递增）、中间=`_`、后缀=`@mail.com`，则依次输入 `test@mail.com`、`tesu@mail.com`...

---

### 7. 从文件输入 (TypeTextFromFile)

**功能：** 从文件（txt/csv/xlsx）中读取内容列表，每次执行输入一行，逐行递增。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 文件路径 | 支持的格式：`.txt`、`.csv`、`.xlsx` | - |

---

### 8. 弹出框 (Popup)

**功能：** 弹出自定义消息框，等待用户点击按钮，根据点击结果返回 true/false，可用于流程控制和人工干预。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 标题 | 弹窗标题 | - |
| 弹出文字 | 弹窗显示的文本内容（支持富文本编辑） | - |
| 字体/颜色 | 自定义弹窗文字的字体和颜色 | Arial 14号 黑色 |
| 图标 | None / Information / Warning / Error / Question | Information |
| 窗口样式 | 正常窗口 / 紧凑窗口 | 正常 |
| 窗口位置 | 屏幕坐标（可点选），-1 表示居中；可切换为屏幕相对坐标（占主屏宽/高的百分比） | 居中 |
| 背景不透明度 | 1~100% | 100% |
| 背景颜色 | 窗口背景颜色 | 白色 |
| 按钮 | 自定义弹窗按钮 | OK |
| 关闭模式 | 可复选项，任一项满足即关闭：点击按钮 / 超时自动关闭（默认 5 秒）/ 到达指定步骤关闭 | 点击按钮 |

**返回值规则：**
- 点击 OK 或 Yes 按钮 → 返回 `true`
- 点击 No 或 Cancel 按钮 → 返回 `false`
- 点击右上角 ✕ 关闭 → 返回 `false`
- 超时自动关闭 → 返回弹窗默认按钮的值（默认 OK，即 `true`）

---

### 9. 窗口聚焦 (FocusWindow)

**功能：** 将指定窗口置于最前方并激活（最小化时先恢复）。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 指定窗口 | 从枚举列表中选择窗口标题（精确匹配优先） | - |
| 标题关键字 | 按关键字包含匹配（不区分大小写） | - |

**使用流程：**
1. 点击「枚举窗口」刷新当前可见窗口列表
2. 从下拉列表选择目标窗口，或输入标题关键字
3. 运行时查找并激活目标窗口，未找到则步骤失败

---

### 10. 统计信息 (Statistics)

**功能：** 执行时打开悬浮统计窗口，实时展示运行时统计信息。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 窗口标题 | 统计窗口标题 | Statistics |
| 窗口位置 | 屏幕坐标（可点选），可切换为屏幕相对坐标（百分比） | (100, 100) |
| 始终置顶 | 窗口是否始终置顶 | 是 |
| 自动关闭 | 自动关闭时间（0=不自动关闭） | 0 |
| 停止运行时关闭 | 运行时点停止后是否关闭统计窗口 | 是 |
| 背景颜色/不透明度 | 窗口外观设置 | 白色 100% |

**可统计项：**
- 总执行时间
- 步骤执行时间（支持按范围筛选：所有/记录日志的/自选步骤）
- 步骤执行次数
- 步骤执行结果（含线程列，主线程与子线程分别统计）
- 当前执行步骤
- 条件计数（可添加多个条件，每个条件可命名和配置规则）

---

### 11. 烧录配置 (BurnInConfig)

**功能：** 配置烧录统计参数，包括判定方式、截图留痕等。全局仅允许一个此类型步骤。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 烧录完成步骤 | 选择代表"一个零件烧录完成"的步骤 | - |
| 判定方式 | 由完成步骤类型自动决定：获取文本步骤→关键字判定；其他→图像判定 | 自动 |
| 良品/不良品/失败关键字 | 关键字模式下的匹配关键字（逗号分隔，任一命中即判定） | - |
| 判据模板图 | 图像模式下的模板图片（良品/不良品/失败） | - |
| 判据相似度阈值 | 图像判定模式下模板匹配的相似度（0~1） | 0.8 |
| 高识别精度 | 图像判定时除结构相似度外还要求颜色相似度达标 | 不勾选 |
| 颜色相似度阈值 | 启用高识别精度时的颜色相似度（0~1） | 0.95 |
| 截图留痕 | 是否启用截图，可设置截图区域（支持屏幕相对坐标）和保存目录 | 关闭 |

**判定优先级：** 不良品 > 烧录失败 > 良品

### 12. 空步骤 (Empty)

**功能：** 用作分隔符、占位符或注释。始终返回成功，不执行任何操作。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 注释 | 可在细节栏填写注释内容（保存到步骤描述字段） | 空 |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |

### 13. 用户输入 (UserInput)

**功能：** 在打开工程 / 开始运行前弹出填写窗口，让使用者输入若干字段；字段值随工程保存，供「上传 Acbel」按字段引用，也可在条件判断中用「用户输入字段」变量读取。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 弹窗标题 | 填写窗口的标题，留空时显示「用户输入」 | 空 |
| 打开工程时询问 | 打开步骤文件后弹出填写窗口（取消不影响工程打开） | 勾选 |
| 开始运行前询问 | 点击运行时、流程开始前弹出填写窗口（取消则中止本次运行） | 不勾选 |
| 字段列表 | 可增删改的字段定义；执行到该步骤时把字段值写入执行上下文 | 无字段 |

**字段属性：**

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 名称 | 字段名，引用与被引用都按名称匹配 | 字段1（新增时按序号生成） |
| 类型 | 单行文本 / 数字 / 日期（yyyy-MM-dd）/ 密码（输入掩码）/ 下拉选择（候选值每行一个） | 单行文本 |
| 值 | 字段当前值，随工程保存，下次打开预填 | 空 |
| 必填 | 运行前未填写则本步骤判为失败（错误类型 TextEmpty） | 不勾选 |
| 冻结 | 首次确认填写后锁定；未登录时只读，尝试修改会提示登录，登录后自动解锁 | 不勾选 |
| 说明 | 显示在弹窗输入框下方的提示文字 | 空 |

**使用流程：**
1. 在详情面板「字段列表」中添加字段，设置名称、类型、是否必填/冻结
2. 需要时点「立即填写」先填一遍（不必等到打开工程或运行）
3. 运行到本步骤时把字段值写入执行上下文；「上传 Acbel」与条件判断即可按字段名引用

### 14. 扫码 (ScanCode)

**功能：** 在 Acbel 上传链条里完成「验证网络 → 弹窗扫码 → 验证条码 → 写入基础资料」；扫码得到的条码作为本步骤的文本结果，供「上传 Acbel」步骤按「扫码结果」引用。

**执行顺序：**

1. 打开数据库连接验证网络（`ACBEL_DATABASE_OPEN`）
2. 弹出扫码窗口等待扫码枪或键盘输入条码（回车 / Tab / 点「确定」返回；扫码枪成串输入后停顿约 350ms 自动确认，条码内的 `\r` `\n` `\t` 会被当作结束符去掉；取消或留空判失败）
3. 验证条码（`CHKBAR_CODE`，站别与工号拼接后作为校验值）
4. 写入基础资料（`ACBEL_SET_BASIC_INFO`：工单号、站别+工号、线别）

**取数来源：** 工单号、站别、工号、线别按字段名从「用户输入」步骤读取（去空格后不区分大小写匹配），站别与工号直接拼接成一个值；任一项为空则本步骤失败并提示先在用户输入步骤中填写。

**参数说明（默认值即用户输入字段的命名约定）：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 工单号字段名 | 取工单号所用的用户输入字段名 | 工单号 |
| 站别字段名 | 取站别所用的用户输入字段名 | 站别 |
| 工号字段名 | 取工号所用的用户输入字段名 | 工号 |
| 线别字段名 | 取线别所用的用户输入字段名 | 线别 |

> 说明：四个字段名随步骤文件保存；默认值与「用户输入」步骤补齐字段时的命名一致，没有特殊需要保持默认即可。

**联动：** 插入扫码步骤时，若缺少「用户输入」步骤、或用户输入步骤位于扫码步骤下方、或缺工单号/站别/工号/线别字段，会先提示再自动创建用户输入步骤（放首行）并补齐字段；插入「上传 Acbel」步骤时也会检查扫码与用户输入步骤是否存在。

**失败处理：** 业务卡控（返回 `0` 类别）失败时弹窗显示厂商返回码与完整详情；连接失败、超时、未扫码等按失败处理并给出原因。

### 15. 上传 Acbel (AcbelUpload)

**功能：** 按 27 段字段规范组装上传资料，先写入基础资料（`ACBEL_SET_BASIC_INFO`），再调用 `ACBEL_INSERT_DATA` 写入 Acbel MES。失败不抛异常，判本步骤失败并带上原因。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 仅校验、不写库 | 试运行：只按字段规范校验组装结果，不打开连接、不调用上传 | 不勾选 |
| 镭雕程式文件名 | 上传的第 3 个参数（独立的段号 0 行） | 空 |
| 必填字段 | 字段规范中标记为必填的段，直接列出 | 空 |
| 选填字段 | 其余选填段，收在「选填字段」折叠区内 | 空 |

**字段值来源：**

- **固定文本**：直接在该行输入框填写
- **引用其他步骤本次运行的结果**：点该行右侧的「▾」菜单选择
  - 普通步骤 → 执行结果（PASS / FAIL）、OCR 文本、直接获取文本、步骤开始时间、步骤结束时间
  - 用户输入步骤 → 该步骤下的某个字段名
  - 扫码步骤 → 扫码结果（条码）

> 时间类引用按 `HHmmss` 取值；开始时间 = 该步骤结束时间减去耗时，开始与结束可以分别引用不同步骤（见 `AcbelReferenceKind.StepStartTime` / `StepEndTime`）。

引用成功后该行显示蓝色引用标签（例如 `12. GetInput_1 · OCR 文本`、`用户输入 → 用户输入_1 / 工号`），点击标签即清除引用并恢复固定文本。

**执行顺序：**

1. 按字段规范校验组装结果（不通过直接判失败，不连数据库）
2. 勾选「仅校验、不写库」时到此结束
3. 首次上传时打开数据库连接并复用该连接
4. 写入基础资料：工单号取 `MO_NO` 段、站别+工号取 `STATION` + `UPD_USER` 段（直接拼接）、线别取 `LINE_NAME` 段；失败则不再执行上传
5. 调用 `ACBEL_INSERT_DATA`；厂商返回内部异常（`2` 类别）时自动重试一次
6. 业务卡控（`0` 类别）失败时弹窗显示返回码与完整详情

### 16. 多线程与信号

「多线程开始」「多线程区域结束」「发出信号」「接收信号」「中断」五个步骤配合使用：把一段步骤交给子线程执行，并在线程之间传递信号或打断主线程。

主流程跑完后会等待子线程把圈定的步骤跑完（点「停止」可立即中断）；子线程使用专用 STA 线程与消息泵，区域内的弹窗等窗口步骤可正常显示。

#### 16.1 多线程开始 (MultiThread)

**功能：** 到达本步骤时新建一个子线程执行「区域」内的步骤，主线程跳过该区域继续往下执行；每次到达本步骤各新建 1 个线程，达到线程个数上限后不再新建。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 线程个数 | 线程总数上限（≥1）；每次运行到本步骤新建 1 个，达到上限后不再新建 | 1 |
| 区域划定方式 | 按结束步骤选择 / 按「多线程区域结束」步骤 | 按结束步骤选择 |
| 结束步骤 | 仅在「按结束步骤选择」时可设，指定区域最后一个步骤（该步骤本身也在区域内）；不选表示到脚本末尾 | 到脚本末尾 |

> 区域不含「多线程开始」步骤本身；选择「按『多线程区域结束』步骤」方式时，取本步骤之后最近的区域结束标记，标记本身不执行。

#### 16.2 多线程区域结束 (MultiThreadEnd)

**功能：** 纯区域标记，本身不执行任何动作，用于与前面的「多线程开始」配对圈定区域。始终返回成功。

#### 16.3 发出信号 (SendSignal)

**功能：** 把配置的值发送到信号中心，同名信号覆盖为最新值。可在步骤之间（含主线程与子线程）传递数据。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 信号名 | 信号名称（区分大小写），不能为空，为空判失败 | 空 |
| 信号类型 | 布尔 / 整数 / 字符串，决定下方信号值的输入形式 | 布尔 |
| 信号值 | 布尔（勾选为 true）、整数或字符串，按信号类型显示对应输入项 | false / 0 / 空 |

#### 16.4 接收信号 (ReceiveSignal)

**功能：** 阻塞等待或立即读取指定信号；取到即消费（清除），收到的内容写入执行结果，可在条件判断中用「信号内容」变量使用。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 信号名 | 信号名称（区分大小写），不能为空 | 空 |
| 信号类型 | 布尔 / 整数 / 字符串，用于校验收到的值 | 布尔 |
| 阻塞等待 | 勾选后在此等待，直到收到信号或等待超时；不勾选则立刻读取（读不到判失败） | 勾选 |
| 等待超时 | 阻塞等待的时间上限（秒），0 表示不限时 | 10 |

> 类型校验不通过（例如期望布尔却收到其它文本）判失败，并给出「信号值类型不匹配」的提示。

#### 16.5 中断 (Interrupt)

**功能：** 由子线程打断主线程，让主线程从指定步骤开始执行（在步骤边界生效）。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 中断后从该步骤开始执行 | 主线程重置到该步骤继续执行 | 未指定 |

**行为限制：**
- 只能由子线程发出；主线程执行到本步骤会判失败（提示「中断步骤只能由子线程发出」）
- 未指定目标步骤判失败；自动化未在运行中发出也判失败
- 多次中断只保留最新一次

## 通用属性

所有步骤都支持以下通用属性：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 启用 | 勾选/取消勾选是否执行该步骤（取消勾选则跳过执行） | 勾选 |
| 名称 | 步骤名称，用于标识与引用 | 自动生成（类型_序号；烧录配置用本地化默认名） |
| 描述 | 步骤描述信息，记录步骤用途 | 空 |
| 等待时间 | 执行前的等待延迟（秒） | 0.1（新建时取设置中的「新建步骤默认等待时间」） |
| 记录执行日志 | 勾选后将执行记录保存到数据库，可在执行日志中查看 | 不勾选 |
| 更多细节 | 仅在勾选「记录执行日志」后出现；开启后执行日志文本里「详情」部分才有内容 | 不勾选 |

### 跳转设置

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 如果真 | 步骤结果为 true 时跳转到指定步骤 | 无跳转 |
| 如果假 | 步骤结果为 false 时跳转到指定步骤 | 无跳转 |
| 自引用上限 | 跳转到自身时的最大次数限制（-1=无限制, 0=禁止, >0=限制次数），达到上限时结果强制为 false | 10 |

### 自定义条件判断

每个步骤支持自定义条件判断，替代默认的执行结果判断：

| 模式 | 说明 |
|------|------|
| 默认 | 使用步骤自身的执行结果 |
| 自定义 | 使用规则行组合判断 |

**条件变量：**

| 变量组 | 可选值 | 说明 |
|--------|--------|------|
| 常量 | 真 / 假 | 恒为真或恒为假 |
| 本步骤 | 执行结果、相似度、执行耗时、点击坐标、OCR 文本、弹窗结果、信号内容 | 取当前步骤本次执行的结果；「信号内容」仅「接收信号」步骤可用 |
| 引用步骤 | 同上（需指定引用步骤） | 取指定步骤最近一次执行的结果 |
| 引用步骤 → 本次被执行 | - | 引用步骤刚刚执行过时为 true（用于统计执行次数） |
| 引用步骤 → 用户输入字段 | 字段名 | 读取「用户输入」步骤指定字段的值（任何步骤都可添加） |

**识别文本提取：** 条件变量为「OCR 文本」时可先对文本做预处理——整段、按行读取（如 `1,3,5-8`）、从指定子串之后读取、从开头读取、从末尾读取；后三种可设读取长度（0=到末尾）与单位（字符/行）。

**运算符：**
- 比较：等于、不等于、大于、小于、大于等于、小于等于
- 字符串：包含、不包含、正则匹配、为空、不为空

**逻辑连接：** 多行条件支持 AND/OR 组合

## 图片编辑窗口

图片编辑窗口是烧录工具的核心辅助功能，用于精确设置图像识别区域和点击位置。在识图步骤（以及「获取文本」的图像相对取点）中点击「编辑」按钮即可打开。

### 图片裁剪

用于从原图中裁剪出精确的识别区域，提高匹配准确率。

**操作方法：**
1. 窗口打开后，主区域显示原图，图上有一个可拖动的裁剪框
2. 拖动裁剪框的边角控制点调整裁剪区域
3. 拖动裁剪框整体移动到目标位置
4. 点击底部「裁剪」按钮确认裁剪

> **提示：** 裁剪区域越小、越精确，识别速度越快、误匹配越少。建议只框选目标元素的关键特征区域。

### 点击点管理

点击点用于指定找到目标图片后，鼠标实际点击的位置。支持添加多个点击点。

**操作方法：**

| 操作 | 方法 |
|------|------|
| 添加点击点 | 顶部菜单 → 「添加点击点」 |
| 移动点击点 | 直接拖拽圆形标记到目标位置 |
| 显示/隐藏全部点击点 | 顶部菜单 → 「全部显示」/「全部隐藏」 |
| 删除单个点击点 | 右键点击点 → 「删除」 |
| 重置单个点击点 | 右键点击点 → 「重置」 |
| 隐藏单个点击点 | 右键点击点 → 「隐藏」 |
| 全部删除 | 顶部菜单 → 「全部删除」 |

**多点击点说明：**
- 每个点击点有编号标识
- 运行时按点击点列表顺序依次点击
- 适用于需要在同一界面多个位置点击的场景

### OCR 识别区域

供「查找识图」步骤在找到图片后对指定区域做文字识别。

| 操作 | 方法 |
|------|------|
| 设置 OCR 区域 | 顶部菜单 → 「设置OCR区域」，在原图上框选范围 |
| 清除 OCR 区域 | 顶部菜单 → 「清除OCR区域」 |

> 区域坐标相对原图像素保存；设置后该步骤的 OCR 识别组才会显示在详情面板中。

### 保存与返回

| 按钮 | 功能 |
|------|------|
| 裁剪 | 确认裁剪区域，生成裁剪后的图片用于识别 |
| 保存 | 保存裁剪图片和点击点配置，关闭编辑窗口返回步骤列表 |
| 另存为 | 把当前裁剪结果另存为图片文件 |
| 返回 | 放弃修改，关闭编辑窗口 |

## 数据存储位置

用户数据统一放在 `%APPDATA%\AutoShaoLu\` 下，OCR 语言数据随程序放在程序目录。

| 数据类型 | 位置 |
|----------|------|
| 步骤文件 | 用户选择的位置（.autostep 打包格式，裁剪图、原图与烧录判据模板随包保存） |
| 用户账号 | `%APPDATA%\AutoShaoLu\users.db`（SQLite） |
| 程序设置 | `%APPDATA%\AutoShaoLu\settings.json` |
| 烧录记录 | `%APPDATA%\AutoShaoLu\burn_in.db`（SQLite） |
| 烧录配置 | `%APPDATA%\AutoShaoLu\burn_in_config.json` |
| 烧录上次会话 | `%APPDATA%\AutoShaoLu\burn_in_last_session.json` |
| 烧录截图 | `%APPDATA%\AutoShaoLu\screenshots\{工令}\yyyyMMdd_HHmmss_fff.png`（保存目录可在烧录配置中改） |
| 最近文件 | `%APPDATA%\AutoShaoLu\recent_files.json`（最多保留 10 条） |
| 执行日志 | `%APPDATA%\AutoShaoLu\execution_log.db`（SQLite） |
| 界面语言 | `%APPDATA%\AutoShaoLu\current_language.txt` |
| OCR 语言数据 | 程序目录下的 `tessdata\`（chi_sim / chi_tra / eng / jpn / equ 等） |

**执行日志分表：** 日志按步骤文件分表保存在同一个 `execution_log.db` 内，表名由步骤文件名派生（保留 ASCII 字母数字，其余字符转下划线，再附 8 位哈希防碰撞，前缀 `StepLog_`；未保存的工程记为 `unsaved`）。未分表的历史数据仍留在主表 `StepExecutionLog` 中。

## 技术栈

- **框架：** .NET Framework 4.8 + WPF（x64）
- **架构：** CommunityToolkit.Mvvm（MVVM）；System.Reactive（图像编辑工具的截图与全局快捷键）

- **日志：** NLog
- **表格导入导出：** EPPlus（xlsx）
- **文档预览：** Microsoft.Web.WebView2（PDF 预览窗口）
- **模拟输入：** InputSimulator
- **文本编码识别：** UTF.Unknown
