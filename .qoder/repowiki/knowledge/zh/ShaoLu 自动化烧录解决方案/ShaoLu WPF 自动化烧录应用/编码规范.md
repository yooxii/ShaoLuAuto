- ViewModel 与 Service 通过 Microsoft.Extensions.DependencyInjection 注册并由 CommunityToolkit.Mvvm 的 Ioc.Default 解析，单例用 AddSingleton、瞬态用 AddTransient。
- 跨层共享状态通过 Utils.SingletonLocator 暴露静态单例（Main、Steps、Settings、UserService），避免构造函数参数膨胀。
- UI 交互统一通过 CommunityToolkit.Mvvm 的 RelayCommand 暴露命令，XAML 中绑定 Command 属性触发逻辑。
- 多语言文案集中放在 Resources/Strings.*.resx，通过 LanguageService.GetLocalizedString 或 WPFLocalizeExtension 读取。
- 异常统一由 NLog 记录，App 层订阅 DispatcherUnhandledException、AppDomain.UnhandledException、TaskScheduler.UnobservedTaskException 做兜底。
