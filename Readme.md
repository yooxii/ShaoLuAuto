# 烧录 (ShaoLu)

一款基于 WPF 的桌面自动化工具，通过图像识别、OCR 文字识别和模拟输入实现 GUI 自动化操作。

---

## 快速开始

1. 启动程序后，在主界面通过步骤列表添加自动化步骤
2. 每个步骤可设置名称、描述、启用/禁用、等待时间、条件跳转等通用属性
3. 点击步骤旁的「编辑」按钮可展开详细参数配置
4. 配置完成后点击「运行」开始执行自动化流程
5. 快捷键：Ctrl+Alt+F9 运行；Ctrl+Alt+F10 停止

---

## 主界面功能

### 文件菜单

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 新建 | Ctrl+N | 清空当前步骤列表 |
| 打开 | Ctrl+O | 打开步骤文件（支持 .autostep 和旧版 .json） |
| 保存 | Ctrl+S | 保存步骤文件 |
| 另存为 | Ctrl+Shift+S | 另存为新文件 |
| 最近打开的文件 | - | 展示最近打开的 10 个文件，点击即可直接打开 |

### 运行控制

- **运行**：开始执行自动化流程
- **暂停/继续**：在步骤间暂停执行，可恢复继续
- **停止**：终止当前运行

### 其他菜单

- **设置**：配置运行行为（运行前确认、最小化运行、调试覆盖层等）和默认参数
- **管理**：登录/注销、用户管理（需管理员权限）
- **执行日志**：查看步骤执行历史记录
- **烧录统计**：查看烧录统计结果（需添加烧录配置步骤）
- **帮助**：打开示例文件和使用文档

## 步骤类型详细说明

### 1. 点击识图 (ClickImage)

**功能：** 在屏幕上查找目标图片，找到后自动点击指定位置。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件（支持 png/jpg/jpeg），点击「选择」按钮选取，或点击「编辑」按钮打开图片编辑窗口裁剪区域和设置点击点 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1，值越高匹配越严格 | 0.85 |
| 鼠标动作 | 找到图片后执行的鼠标动作序列（左键/右键/双击/长按/滚轮/拖拽），支持添加多个动作 | 左键单击 1 次 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒），超时未找到则步骤失败 | 3 |

**使用流程：**
1. 点击「选择」按钮选取目标图片（截取屏幕上某个按钮或图标的截图）
2. 点击「编辑」按钮打开图片编辑窗口，裁剪出精确的识别区域，并添加点击位置标记
3. 调整相似度阈值（建议 0.8~0.95，越高越严格）
4. 配置鼠标动作（可组合多种动作，如：左键点击 → 滚轮滚动）

---

### 2. 查找识图 (FindImage)

**功能：** 在屏幕上查找目标图片，仅判断是否找到（不点击），可用于条件判断。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标图片 | 选择需要识别的目标图片文件 | - |
| 相似度阈值 | 图片匹配的相似度，范围 0~1 | 0.85 |
| 等待时间 | 执行本步骤前的等待时间（秒） | 0.1 |
| 查找间隔 | 重复查找的时间间隔（秒） | 0.1 |
| 超时时间 | 查找图片的最大超时时间（秒） | 3 |

**使用流程：**
1. 选择目标图片（同样支持「编辑」裁剪识别区域）
2. 设置相似度和超时参数
3. 步骤执行结果：找到为 `true`，未找到为 `false`
4. 可配合条件跳转实现条件分支

---

### 3. 获取输入 (GetInput)

**功能：** 从屏幕指定区域获取文本信息，支持 OCR 识别和 UI Automation 读取可选择文本两种模式。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 获取方式 | OCR（屏幕区域文字识别）或 ScreenText（读取可选择文本） | OCR |
| OCR 区域 | 框选屏幕区域用于 OCR 识别 | - |
| 文本位置 | ScreenText 模式下点选屏幕位置读取文本 | - |
| 等待时间 | 执行前的等待时间（秒） | 0.1 |

**使用流程：**
1. 选择获取方式
2. OCR 模式：点击「选择区域」框选屏幕区域
3. ScreenText 模式：点击「选择位置」点选屏幕上的文本控件
4. 点击「测试」可预览识别结果
5. 识别结果可通过条件变量 `Self_OCRText` 被后续步骤引用

---

### 4. 鼠标操作 (MouseAction)

**功能：** 在指定屏幕位置执行鼠标动作，不依赖图像识别。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 位置模式 | 绝对坐标（指定屏幕坐标）或鼠标当前位置 | 绝对坐标 |
| 目标坐标 | 屏幕绝对坐标（逻辑像素），可通过「选取坐标点」全屏点选 | (0, 0) |
| 动作列表 | 顺序执行的鼠标动作序列 | 左键单击 1 次 |

**支持的动作类型：**
- 左键单击、右键单击、双击
- 左键长按（按住时长 = 间隔时间）
- 滚轮上/下
- 拖拽（可编辑拖拽路径）

---

### 5. 输入文字 (TypeText)

**功能：** 模拟键盘输入一段文字。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 输入内容 | 需要输入的文本内容 | - |
| 按键间隔 | 每个按键之间的延迟时间（秒），设为 0 则使用安全快速输入模式 | 0.05 |

---

### 6. 多次输入 (TypeTextMore)

**功能：** 按照前缀、中间、后缀的组合格式，批量循环输入多段文字。每次执行后自动递增标记了「递增」的文本片段。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 前缀/中间/后缀 | 组合输入的文本片段，各自可设置是否递增 | - |

**示例：** 前缀=`test`（递增）、中间=`_`、后缀=`@mail.com`，则依次输入 `test@mail.com`、`tesu@mail.com`...

---

### 7. 从文件输入 (TypeTextFromFile)

**功能：** 从文件（txt/csv/xlsx）中读取内容列表，每次执行输入一行，逐行递增。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 等待时间 | 执行前的等待时间（秒） | 0.1 |
| 按键间隔 | 每个按键之间的延迟（秒） | 0.01 |
| 文件路径 | 支持的格式：`.txt`、`.csv`、`.xlsx` | - |

---

### 8. 弹出框 (Popup)

**功能：** 弹出自定义消息框，等待用户点击按钮，根据点击结果返回 true/false，可用于流程控制和人工干预。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 标题 | 弹窗标题 | - |
| 弹出文字 | 弹窗显示的文本内容（支持富文本编辑） | - |
| 字体/颜色 | 自定义弹窗文字的字体和颜色 | Arial 14号 黑色 |
| 图标 | None / Information / Warning / Error / Question | Information |
| 窗口样式 | 正常窗口 / 紧凑窗口 | 正常 |
| 窗口位置 | 屏幕坐标（可点选），-1 表示居中 | 居中 |
| 背景不透明度 | 0~100% | 100% |
| 背景颜色 | 窗口背景颜色 | 白色 |
| 按钮 | 自定义弹窗按钮 | OK |
| 关闭模式 | 点击按钮 / 超时自动关闭 / 到达指定步骤关闭 | 点击按钮 |

**返回值规则：**
- 点击 OK 或 Yes 按钮 → 返回 `true`
- 点击 No 或 Cancel 按钮 → 返回 `false`
- 点击右上角 ✕ 关闭 → 返回 `false`

---

### 9. 窗口聚焦 (FocusWindow)

**功能：** 将指定窗口置于最前方并激活（最小化时先恢复）。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 指定窗口 | 从枚举列表中选择窗口标题（精确匹配优先） | - |
| 标题关键字 | 按关键字包含匹配（不区分大小写） | - |

**使用流程：**
1. 点击「枚举窗口」刷新当前可见窗口列表
2. 从下拉列表选择目标窗口，或输入标题关键字
3. 运行时查找并激活目标窗口，未找到则步骤失败

---

### 10. 统计信息 (Statistics)

**功能：** 执行时打开悬浮统计窗口，实时展示运行时统计信息。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 窗口标题 | 统计窗口标题 | Statistics |
| 窗口位置 | 屏幕坐标（可点选） | (100, 100) |
| 始终置顶 | 窗口是否始终置顶 | 是 |
| 自动关闭 | 自动关闭时间（0=不自动关闭） | 0 |
| 背景颜色/不透明度 | 窗口外观设置 | 白色 100% |

**可统计项：**
- 总执行时间
- 步骤执行时间（支持按范围筛选：所有/记录日志的/自选步骤）
- 步骤执行次数
- 步骤执行结果
- 自定义条件（可添加多个，每个条件可命名和配置规则）

---

### 11. 烧录配置 (BurnInConfig)

**功能：** 配置烧录统计参数，包括判定方式、截图留痕等。全局仅允许一个此类型步骤。

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 烧录完成步骤 | 选择代表"一个零件烧录完成"的步骤 | - |
| 判定方式 | 由完成步骤类型自动决定：获取输入步骤→关键字判定；其他→图像判定 | 自动 |
| 良品/不良品/失败关键字 | 关键字模式下的匹配关键字（逗号分隔） | - |
| 判据模板图 | 图像模式下的模板图片（良品/不良品/失败） | - |
| 截图留痕 | 是否启用截图，可设置截图区域和保存目录 | 关闭 |

**判定优先级：** 不良品 > 烧录失败 > 良品

---

### 12. 空步骤 (Empty)

**功能：** 用作分隔符、占位符或注释。始终返回成功，不执行任何操作。

**参数说明：**

| 参数 | 说明 |
|------|------|
| 注释 | 可在细节栏填写注释内容 |

## 通用属性

所有步骤都支持以下通用属性：

| 属性 | 说明 |
|------|------|
| 启用 | 勾选/取消勾选是否启用该步骤（取消勾选则跳过执行） |
| 名称 | 步骤名称，用于标识 |
| 描述 | 步骤描述信息，记录步骤用途 |
| 等待时间 | 执行前的等待延迟（秒） |
| 记录执行日志 | 勾选后将执行记录保存到数据库，可在执行日志中查看 |

### 跳转设置

| 属性 | 说明 |
|------|------|
| 如果真 | 步骤结果为 true 时跳转到指定步骤 |
| 如果假 | 步骤结果为 false 时跳转到指定步骤 |
| 自引用上限 | 跳转到自身时的最大次数限制（-1=无限制, 0=禁止, >0=限制次数），达到上限时结果强制为 false |

### 自定义条件判断

每个步骤支持自定义条件判断，替代默认的执行结果判断：

| 模式 | 说明 |
|------|------|
| 默认 | 使用步骤自身的执行结果 |
| 自定义 | 使用规则行组合判断 |

**条件变量类型：**
- 常量：真 / 假
- 本步骤：执行结果、相似度、执行耗时、点击坐标、OCR文本、弹窗结果
- 引用步骤：同上（需指定引用步骤）
- 引用步骤 → 本次被执行：仅当引用步骤刚刚执行时为 true（用于统计执行次数）

**运算符：**
- 比较：等于、不等于、大于、小于、大于等于、小于等于
- 字符串：包含、不包含、正则匹配、为空、不为空

**逻辑连接：** 多行条件支持 AND/OR 组合

## 图片编辑窗口

图片编辑窗口是烧录工具的核心辅助功能，用于精确设置图像识别区域和点击位置。在识图步骤中点击「编辑」按钮即可打开。

### 图片裁剪

用于从原图中裁剪出精确的识别区域，提高匹配准确率。

**操作方法：**
1. 窗口打开后，主区域显示原图，图上有一个可拖动的裁剪框
2. 拖动裁剪框的边角控制点调整裁剪区域
3. 拖动裁剪框整体移动到目标位置
4. 点击底部「裁剪」按钮确认裁剪

> **提示：** 裁剪区域越小、越精确，识别速度越快、误匹配越少。建议只框选目标元素的关键特征区域。

### 点击点管理

点击点用于指定找到目标图片后，鼠标实际点击的位置。支持添加多个点击点。

**操作方法：**

| 操作 | 方法 |
|------|------|
| 添加点击点 | 顶部菜单 → 「添加点击点」 |
| 移动点击点 | 直接拖拽红色圆形标记到目标位置 |
| 删除单个点击点 | 右键点击点 → 「删除」 |
| 全部删除 | 顶部菜单 → 「全部删除」 |

**多点击点说明：**
- 每个点击点有编号标识
- 运行时按点击点列表顺序依次点击
- 适用于需要在同一界面多个位置点击的场景

### 保存与返回

| 按钮 | 功能 |
|------|------|
| 裁剪 | 确认裁剪区域，生成裁剪后的图片用于识别 |
| 保存 | 保存裁剪图片和点击点配置，关闭编辑窗口返回步骤列表 |
| 返回 | 放弃修改，关闭编辑窗口 |

## 数据存储位置

| 数据类型 | 位置 |
|----------|------|
| 步骤文件 | 用户选择的位置（.autostep 格式） |
| 烧录记录 | `%APPDATA%\AutoShaoLu\burn_in.db` |
| 烧录截图 | `%APPDATA%\AutoShaoLu\screenshots\{工令}\`（可自定义） |
| 最近文件 | `%APPDATA%\AutoShaoLu\recent_files.json` |
| 执行日志 | `%APPDATA%\AutoShaoLu\execution_logs.db` |
| OCR 语言数据 | 程序目录下的 `tessdata\` |

## 技术栈

- **框架：** .NET Framework 4.8, WPF
- **OCR：** TesseractOCR 5.5.2
- **图像识别：** OpenCvSharp4
- **数据库：** SQLite (FreeSql)
- **UI 组件：** WPFDevelopers
- **本地化：** WPFLocalizeExtension (支持中文简体/繁体/英文)
